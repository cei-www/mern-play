Step C.1: POST /api/tasks: 201 and the body

Now a test that changes data. You send a JSON body: build a dictionary with Create Dictionary and pass it as json=; the library converts it and sets the header for you.

The title starts with Robot on purpose. Later you will delete every task with that prefix after each test. In Robot a number must be written ${2}, otherwise it is the text "2".

ตอนนี้เป็นเทสต์ที่ เปลี่ยน ข้อมูล คุณส่ง body แบบ JSON: สร้าง dictionary ด้วย Create Dictionary แล้วส่งเป็น json= library จะแปลงและตั้ง header ให้เอง

title ขึ้นต้นด้วย Robot โดยตั้งใจ ภายหลังคุณจะลบทุก task ที่มี prefix นี้หลังเทสต์แต่ละตัว ใน Robot ตัวเลขต้องเขียน ${2} ไม่เช่นนั้นจะเป็น ข้อความ "2"

Create the file tests/03_tasks_create.robot (in the Explorer: api › tests › 03_tasks_create.robot) (right-click the folder in the Explorer, then New File).

*** Settings ***
Library    RequestsLibrary

*** Variables ***
${BASE_URL}    http://localhost:3001

*** Test Cases ***
Create Task Returns 201 And The Task
    ${body}=    Create Dictionary    title=Robot task one    priority=${2}
    ${response}=    POST    ${BASE_URL}/api/tasks    json=${body}
    Should Be Equal As Integers    ${response.status_code}    201
    Should Be Equal    ${response.json()}[title]    Robot task one
    Should Be True    ${response.json()}[id] > 0
robot --outputdir results tests/03_tasks_create.robot

Hint

Pass the dictionary with json=${body}. The new task comes back with an id: ${response.json()}[id].
