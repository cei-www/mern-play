Step C.5: Setup and teardown: reset the data

Your tests have created tasks called Robot .... A Test Teardown runs after every test, even when it failed, and deletes them. Execute Sql String runs one SQL statement. This keeps the database in the same state before every run.

เทสต์ของคุณสร้าง task ชื่อ Robot ... ไว้ Test Teardown ทำงานหลังเทสต์ ทุกตัว แม้จะล้ม และลบ task เหล่านั้น Execute Sql String รัน SQL หนึ่งคำสั่ง ทำให้ฐานข้อมูลอยู่ในสภาพเดิมก่อนการรันทุกครั้ง

Edit tests/03_tasks_create.robot (in the Explorer: api › tests › 03_tasks_create.robot). Add this line to the Settings, after the Suite Teardown line:

Test Teardown    Execute Sql String    DELETE FROM tasks WHERE title LIKE 'Robot %'

Run the file twice. Then check in the Database tab that no Robot ... task is left (use the SQL command SELECT title FROM tasks WHERE title LIKE 'Robot %'; the viewer can only read this database).

รันไฟล์สองครั้ง แล้วดูใน tab Database ว่าไม่มี task Robot ... เหลือ (ใช้ SQL command SELECT title FROM tasks WHERE title LIKE 'Robot %' ผู้ใช้ viewer อ่านฐานข้อมูลนี้ได้อย่างเดียว)

Hint

Use LIKE 'Robot %' with a space after Robot. Setup and teardown can be set for the whole suite (Suite Setup) or for each test (Test Teardown).

Solution

In tests/03_tasks_create.robot:

Test Teardown    Execute Sql String    DELETE FROM tasks WHERE title LIKE 'Robot %'
