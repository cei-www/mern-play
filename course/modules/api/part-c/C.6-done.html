Step C.6: PATCH done and completed_at in the database

Marking a task as done must set completed_at in the database, and the API answer alone does not prove it. Create a task, mark it done with PATCH, then read completed_at with SQL. completed_at IS NOT NULL gives 1 when the time is set.

การทำเครื่องหมายว่าเสร็จต้องตั้ง completed_at ในฐานข้อมูล และคำตอบของ API อย่างเดียวพิสูจน์ไม่ได้ สร้าง task ทำเครื่องหมายด้วย PATCH แล้วอ่าน completed_at ด้วย SQL completed_at IS NOT NULL ให้ค่า 1 เมื่อมีเวลาตั้งไว้

Edit tests/03_tasks_create.robot (in the Explorer: api › tests › 03_tasks_create.robot).

Marking A Task Done Sets Completed At
    ${body}=    Create Dictionary    title=Robot done task
    ${created}=    POST    ${BASE_URL}/api/tasks    json=${body}
    ${id}=    Set Variable    ${created.json()}[id]
    ${done}=    Create Dictionary    done=${True}
    ${response}=    PATCH    ${BASE_URL}/api/tasks/${id}/done    json=${done}
    Should Be Equal As Integers    ${response.json()}[done]    1
    ${rows}=    Query    SELECT completed_at IS NOT NULL FROM tasks WHERE id = ${id}
    Should Be Equal As Integers    ${rows}[0][0]    1

Hint

The keyword PATCH works like POST. The path is ${BASE_URL}/api/tasks/${id}/done and the body is done=${True}.
