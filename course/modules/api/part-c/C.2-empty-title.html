Step C.2: An empty title returns 400

First reproduce it by hand: in Swagger (reference API) run createTask with { "title": "" } and read the 400 answer. Then automate it. ${EMPTY} is the empty text.

เริ่มจากทำซ้ำด้วยมือ: ใน Swagger (reference API) รัน createTask ด้วย { "title": "" } และอ่านคำตอบ 400 จากนั้นจึงทำให้เป็นอัตโนมัติ ${EMPTY} คือข้อความว่าง
