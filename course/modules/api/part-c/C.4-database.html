Step C.4: Check the database too

An API can answer 201 and still forget to save the row. So a good test looks behind the API, in MySQL. DatabaseLibrary connects with Connect To Database and runs SQL with Query, which returns a list of rows; each row is a list of values, so ${rows}[0][0] is the first column of the first row.

The connection is opened once for the whole file with Suite Setup and closed with Suite Teardown. Add these lines to the Settings of the file (right after Library RequestsLibrary), and add the new test at the end.

API อาจตอบ 201 แต่ลืมบันทึกแถว เทสต์ที่ดีจึงมอง เบื้องหลัง API ไปถึง MySQL ด้วย DatabaseLibrary เชื่อมต่อด้วย Connect To Database และรัน SQL ด้วย Query ซึ่งคืน list ของแถว แต่ละแถวเป็น list ของค่า ${rows}[0][0] จึงเป็นคอลัมน์แรกของแถวแรก

เปิดการเชื่อมต่อครั้งเดียวทั้งไฟล์ด้วย Suite Setup และปิดด้วย Suite Teardown เพิ่มบรรทัดเหล่านี้ใน Settings ของไฟล์ (ต่อจาก Library RequestsLibrary) และเพิ่มเทสต์ใหม่ท้ายไฟล์

Edit tests/03_tasks_create.robot (in the Explorer: api › tests › 03_tasks_create.robot). First the settings:

Library    DatabaseLibrary
Suite Setup    Connect To Database    pymysql    db_name=taskapp_test    db_user=robot    db_password=robot_pw    db_host=db    db_port=3306
Suite Teardown    Disconnect From All Databases

Edit tests/03_tasks_create.robot (in the Explorer: api › tests › 03_tasks_create.robot). Then the test, at the end of the file:

Created Task Is Stored In The Database
    ${body}=    Create Dictionary    title=Robot stored task    priority=${3}
    ${response}=    POST    ${BASE_URL}/api/tasks    json=${body}
    ${id}=    Set Variable    ${response.json()}[id]
    ${rows}=    Query    SELECT title, priority FROM tasks WHERE id = ${id}
    Should Be Equal    ${rows}[0][0]    Robot stored task
    Should Be Equal As Integers    ${rows}[0][1]    3

The database host is db (its name inside Docker), with the user robot that may only use taskapp_test. Run the file. You can also open the Database tab to see the rows.

host ของฐานข้อมูลคือ db (ชื่อภายใน Docker) กับผู้ใช้ robot ที่ใช้ได้เฉพาะ taskapp_test รันไฟล์ แล้วเปิด tab Database ดูแถวได้ด้วย

Hint

"Connection refused" or "Unknown database" means a typo in the Connect To Database line: the arguments are db_name, db_user, db_password, db_host and db_port.
