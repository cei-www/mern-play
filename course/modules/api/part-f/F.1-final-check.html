Step F.1: Final check

The final check does two things.

  1. It runs all your tests. They must all pass (at least 20 of them).
  2. It runs them again against a broken API. The reference API has secret switches that make it misbehave in a specific way (a "mutant"): it accepts an empty title, or forgets completed_at, or accepts a dangerous sort. For each bug at least one of your tests must fail. If every test still passes, your tests would not have noticed the bug in real life.

This is called a mutation check. The switches are controlled by the check only; you cannot use them from the page.

การตรวจสุดท้ายทำสองอย่าง

  1. รันเทสต์ทั้งหมดของคุณ ทุกตัวต้องผ่าน (อย่างน้อย 20 ตัว)
  2. รันอีกครั้งกับ API ที่ถูกทำให้พัง reference API มีสวิตช์ลับที่ทำให้มันผิดพลาดแบบเฉพาะเจาะจง ("mutant"): ยอมรับ title ว่าง หรือลืม completed_at หรือยอมรับ sort ที่อันตราย สำหรับบั๊กแต่ละตัว เทสต์ของคุณอย่างน้อยหนึ่งตัวต้อง ล้ม ถ้าทุกเทสต์ยังผ่านอยู่ เทสต์ของคุณก็จะไม่สังเกตเห็นบั๊กนี้ในชีวิตจริง

เรียกว่า mutation check สวิตช์ควบคุมโดยการตรวจเท่านั้น คุณใช้จากหน้าเว็บไม่ได้

Run it from the terminal of the Robot tab. It takes about 20 seconds because it runs your tests four times:

รันจาก terminal ของ tab Robot ใช้เวลาประมาณ 20 วินาที เพราะรันเทสต์ของคุณสี่ครั้ง:

  PASS  All your Robot tests pass
  PASS  Your tests catch deliberate bugs
Hint

"Not caught" lines tell you which kind of test is missing, for example "no test sends an empty title and expects 400". Add that test and run the check again. If your own tests fail first, fix them (read results/log.html).
