Step E.3: An unsafe sort value returns 400

The API accepts only four values for sort and must refuse anything else with 400 (module build, Story 5). Without this test, a future change could open a hole without anyone noticing. Add it to the same file.

API ยอมรับ sort เพียงสี่ค่า และต้องปฏิเสธอย่างอื่นด้วย 400 (module build Story 5) ถ้าไม่มีเทสต์นี้ การแก้ไขในอนาคตอาจเปิดช่องโหว่โดยไม่มีใครสังเกต เพิ่มเทสต์นี้ในไฟล์เดียวกัน
