Step E.1: Data-driven tests with Test Template

Many invalid titles should be rejected: empty, only spaces, too long. Writing one test per case is long. With a test template you write the steps once (as a keyword) and each test case is just a row of data.

Test Template Title Should Be Rejected says "every test in this file calls that keyword". The heading *** Test Cases *** TITLE names the data column. ${SPACE} is a space and ${{'x' * 101}} runs a bit of Python: 101 letters.

title ที่ไม่ถูกต้องหลายแบบควรถูกปฏิเสธ: ว่าง มีแต่ช่องว่าง ยาวเกินไป การเขียนหนึ่งเทสต์ต่อหนึ่งกรณียาวเกินไป ด้วย test template คุณเขียนขั้นตอน ครั้งเดียว (เป็น keyword) และแต่ละเทสต์ก็เป็นแค่แถวข้อมูล

Test Template Title Should Be Rejected หมายถึง "ทุกเทสต์ในไฟล์นี้เรียก keyword นั้น" หัวตาราง *** Test Cases *** TITLE ตั้งชื่อคอลัมน์ข้อมูล ${SPACE} คือช่องว่าง และ ${{'x' * 101}} รันโค้ด Python สั้น ๆ: ตัวอักษร 101 ตัว

Create the file tests/06_data_driven.robot (in the Explorer: api › tests › 06_data_driven.robot) (right-click the folder in the Explorer, then New File).

*** Settings ***
Resource    ../resources/api.resource
Test Template    Title Should Be Rejected

*** Test Cases ***    TITLE
Empty Title    ${EMPTY}
Spaces Only    ${SPACE}${SPACE}
Too Long    ${{'x' * 101}}

*** Keywords ***
Title Should Be Rejected
    [Arguments]    ${title}
    ${body}=    Create Dictionary    title=${title}
    ${response}=    POST    ${BASE_URL}/api/tasks    json=${body}    expected_status=400
    Should Contain    ${response.json()}[error]    title
robot --outputdir results tests/06_data_driven.robot

Each row appears as its own test in the report. Add a fourth row of your own, for example a title with only a tab.

แต่ละแถวปรากฏเป็นเทสต์ของตัวเองในรายงาน เพิ่มแถวที่สี่ของคุณเอง เช่น title ที่มีแต่ tab

Hint

The header row and the data rows are separated by two or more spaces. A row whose name is Empty Title and whose data is ${EMPTY} calls the template keyword with an empty title.
