Step E.2: Tags and --include

A tag is a label on a test. Test Tags regression in the Settings gives every test in the file that tag, and [Tags] smoke adds a label to one test. You choose which tests to run by tag:

tag คือป้ายที่ติดบนเทสต์ Test Tags regression ใน Settings ให้ tag นั้นกับทุกเทสต์ในไฟล์ และ [Tags] smoke ติดป้ายให้เทสต์หนึ่งตัว คุณเลือกรันเทสต์ตาม tag ได้:

robot --outputdir results --include smoke tests

A smoke test is a very small test that answers "is it alive at all?". It is the first thing you run after every start.

smoke test คือเทสต์เล็กมากที่ตอบว่า "มันยังมีชีวิตอยู่ไหม?" เป็นสิ่งแรกที่รันหลังเริ่มระบบทุกครั้ง

Create the file tests/07_smoke_and_security.robot (in the Explorer: api › tests › 07_smoke_and_security.robot) (right-click the folder in the Explorer, then New File).

*** Settings ***
Resource    ../resources/api.resource
Test Tags    regression

*** Test Cases ***
Health Is Up
    [Tags]    smoke
    ${response}=    GET    ${BASE_URL}/api/health
    Should Be Equal As Integers    ${response.status_code}    200

Task List Is Not Empty
    [Tags]    smoke
    ${response}=    GET    ${BASE_URL}/api/tasks
    Should Not Be Empty    ${response.json()}

Open Tasks Filter Works
    ${response}=    GET    ${BASE_URL}/api/tasks    params=done=0
    Should Be Equal As Integers    ${response.status_code}    200

Run only the smoke tests, then everything. Open the report and look at the Statistics by Tag table.

รันเฉพาะ smoke แล้วรันทั้งหมด เปิดรายงานแล้วดูตาราง Statistics by Tag

Open report.html

Hint

A test can have several tags. --exclude smoke does the opposite of --include smoke.
