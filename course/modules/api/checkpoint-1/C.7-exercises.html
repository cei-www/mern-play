Step C.7: Checkpoint 1: two exercises

About 15 minutes. Both exercises are optional. Try first, then the hint, and only then the solution. A good test fails when the API is wrong: your tests will be checked against deliberate bugs.

ใช้เวลาประมาณ 15 นาที โจทย์ทั้งสองข้อเป็นทางเลือก ลองทำเองก่อน แล้วค่อยเปิด hint และเปิด solution เป็นลำดับสุดท้าย เทสต์ที่ดีต้อง ล้ม เมื่อ API ผิด: เทสต์ของคุณจะถูกตรวจกับบั๊กที่ใส่ไว้โดยตั้งใจ

Exercise 1 (easier): the groups contain Work

Write a test named Groups Contain Work. It calls GET /api/groups, expects status 200 and checks that one of the groups is called Work.

เขียนเทสต์ชื่อ Groups Contain Work เรียก GET /api/groups คาดหวัง status 200 และตรวจว่ามี group หนึ่งชื่อ Work

Create the file tests/04_checkpoint_1.robot (in the Explorer: api › tests › 04_checkpoint_1.robot).

Hint

Collect the names in a list: ${names}= Create List, then Append To List ${names} ${group}[name] inside a FOR loop (the library Collections has these keywords). Finish with Should Contain ${names} Work.

Solution

In tests/04_checkpoint_1.robot (the whole file so far):

*** Settings ***
Library    RequestsLibrary
Library    Collections

*** Variables ***
${BASE_URL}    http://localhost:3001

*** Test Cases ***
Groups Contain Work
    ${response}=    GET    ${BASE_URL}/api/groups
    Should Be Equal As Integers    ${response.status_code}    200
    ${names}=    Create List
    FOR    ${group}    IN    @{response.json()}
        Append To List    ${names}    ${group}[name]
    END
    Should Contain    ${names}    Work

Exercise 2 (harder): an empty group name is rejected

Write a test named Empty Group Name Is Rejected And Adds No Row. It counts the rows of task_groups, sends POST /api/groups with an empty name, expects 400, counts again and checks that the number did not change.

เขียนเทสต์ชื่อ Empty Group Name Is Rejected And Adds No Row นับแถวของ task_groups ส่ง POST /api/groups ด้วยชื่อว่าง คาดหวัง 400 นับอีกครั้ง และตรวจว่าจำนวนไม่เปลี่ยน

Edit tests/04_checkpoint_1.robot (in the Explorer: api › tests › 04_checkpoint_1.robot). First the database settings (after the line Library Collections), then the test at the end.

Hint

Use the same Suite Setup and Suite Teardown lines as in step C.4. Query SELECT COUNT(*) FROM task_groups returns the count as ${rows}[0][0].

Solution

In tests/04_checkpoint_1.robot, after Library Collections:

Library    DatabaseLibrary
Suite Setup    Connect To Database    pymysql    db_name=taskapp_test    db_user=robot    db_password=robot_pw    db_host=db    db_port=3306
Suite Teardown    Disconnect From All Databases
Solution

In tests/04_checkpoint_1.robot, at the end:

Empty Group Name Is Rejected And Adds No Row
    ${before}=    Query    SELECT COUNT(*) FROM task_groups
    ${body}=    Create Dictionary    name=${EMPTY}
    ${response}=    POST    ${BASE_URL}/api/groups    json=${body}    expected_status=400
    ${after}=    Query    SELECT COUNT(*) FROM task_groups
    Should Be Equal As Integers    ${after}[0][0]    ${before}[0][0]
  PASS  The test "Groups Contain Work" passes and catches a missing group
  PASS  The test "Empty Group Name Is Rejected And Adds No Row" passes and catches a bad API
