Step B.5: Query strings: filter and sort

Test the options of the list. params=done=0 adds ?done=0 to the URL. A FOR loop checks every task of the answer: the loop body is indented and the loop ends with END.

To test sorting without depending on the data, check the property: each priority is greater than or equal to the one before it.

ทดสอบตัวเลือกของรายการ params=done=0 ต่อ ?done=0 ท้าย URL ลูป FOR ตรวจ task ทุกชิ้น ในคำตอบ: เนื้อลูปเยื้องเข้าไป และลูปจบด้วย END

เพื่อทดสอบการเรียงลำดับโดยไม่ผูกกับข้อมูล ให้ตรวจ คุณสมบัติ: priority แต่ละตัวมากกว่าหรือเท่ากับตัวก่อนหน้า

Edit tests/02_tasks_read.robot (in the Explorer: api › tests › 02_tasks_read.robot).

Open Filter Returns Only Open Tasks
    ${response}=    GET    ${BASE_URL}/api/tasks    params=done=0
    ${tasks}=    Set Variable    ${response.json()}
    FOR    ${task}    IN    @{tasks}
        Should Be Equal As Integers    ${task}[done]    0
    END

Sort By Priority Is Ascending
    ${response}=    GET    ${BASE_URL}/api/tasks    params=sort=priority&order=asc
    ${tasks}=    Set Variable    ${response.json()}
    ${previous}=    Set Variable    ${0}
    FOR    ${task}    IN    @{tasks}
        Should Be True    ${task}[priority] >= ${previous}
        ${previous}=    Set Variable    ${task}[priority]
    END
robot --outputdir results tests/02_tasks_read.robot
