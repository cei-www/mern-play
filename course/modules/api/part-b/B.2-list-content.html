Step B.2: Read the JSON: count and fields

${response.json()} turns the answer into Python data: a list of dictionaries. Get Length counts the items. Dictionary Should Contain Key comes from the library Collections (you added it at the top of the file in step B.1).

Prefer checks that stay true when the data changes. "At least ten tasks" is better than "exactly fourteen".

${response.json()} แปลงคำตอบเป็นข้อมูล Python: list ของ dictionary Get Length นับจำนวนรายการ Dictionary Should Contain Key มาจาก library Collections (ใส่ไว้ที่ต้นไฟล์แล้วในโค้ดของบทเรียนนี้)
