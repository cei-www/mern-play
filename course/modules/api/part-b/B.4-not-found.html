Step B.4: Not found must be 404

A test for the failure case is as important as one for success. Ask for a task that does not exist and expect 404.

Important: RequestsLibrary treats every 4xx and 5xx answer as a failure of the keyword by default, so the test would stop at the GET line. When you expect such a status, say so with expected_status=404.

เทสต์กรณีล้มเหลวสำคัญเท่ากับเทสต์กรณีสำเร็จ ขอ task ที่ไม่มีอยู่และคาดหวัง 404

สำคัญ: โดยปริยาย RequestsLibrary ถือว่าคำตอบ 4xx และ 5xx ทุกตัวเป็น ความล้มเหลว ของ keyword เทสต์จึงหยุดที่บรรทัด GET เมื่อคุณ คาดหวัง status แบบนั้น ให้บอกด้วย expected_status=404

Edit tests/02_tasks_read.robot (in the Explorer: api › tests › 02_tasks_read.robot).

Unknown Task Returns 404
    ${response}=    GET    ${BASE_URL}/api/tasks/999999    expected_status=404
    Should Be Equal    ${response.json()}[error]    Task not found
