Step A.2: How a Robot file looks

A Robot Framework test is a plain text file ending in .robot. It has up to four sections. Each starts with a line of three stars:

  • *** Settings ***: libraries to use (Library RequestsLibrary), setup and teardown.
  • *** Variables ***: named values, written ${NAME} value.
  • *** Test Cases ***: the tests. A name on the left edge, then indented lines of steps.
  • *** Keywords ***: your own reusable steps (Part D).

Every step is a keyword (a ready-made action such as GET or Should Be Equal) followed by its arguments. Separate the pieces with two or more spaces (or a tab). One space is part of a name: Should Be Equal is one keyword, because it has single spaces inside.

Results are stored in variables with ${name}= Keyword .... You read parts of a variable with brackets: ${response.status_code}, ${data}[0][title].

เทสต์ของ Robot Framework คือไฟล์ข้อความธรรมดาที่ลงท้ายด้วย .robot มี section ได้สูงสุดสี่แบบ แต่ละอันขึ้นต้นด้วยบรรทัดที่มีดาวสามดวง:

  • *** Settings ***: library ที่ใช้ (Library RequestsLibrary) รวมถึง setup และ teardown
  • *** Variables ***: ค่าที่ตั้งชื่อ เขียนเป็น ${NAME} value
  • *** Test Cases ***: ตัวเทสต์ ชื่ออยู่ชิดซ้าย แล้วตามด้วยบรรทัดที่เยื้องเข้าไปเป็นขั้นตอน
  • *** Keywords ***: ขั้นตอนที่คุณสร้างเองเพื่อใช้ซ้ำ (Part D)

แต่ละขั้นตอนคือ keyword (การกระทำสำเร็จรูป เช่น GET หรือ Should Be Equal) ตามด้วย argument คั่นแต่ละส่วนด้วยช่องว่างตั้งแต่สองช่องขึ้นไป (หรือ tab) ช่องว่างเดียวถือเป็นส่วนของชื่อ: Should Be Equal เป็น keyword เดียว เพราะมีช่องว่างเดียวคั่น

เก็บผลลัพธ์ในตัวแปรด้วย ${name}= Keyword ... และอ่านบางส่วนของตัวแปรด้วยวงเล็บเหลี่ยม: ${response.status_code}, ${data}[0][title]

*** Test Cases ***
Health Returns 200
    ${response}=    GET    http://localhost:3001/api/health
    Should Be Equal As Integers    ${response.status_code}    200

This is the shape of the test you write next. Notice the four spaces before each step and the two or more spaces between the pieces.

นี่คือรูปแบบของเทสต์ที่คุณจะเขียนต่อไป สังเกตช่องว่างสี่ช่องหน้าแต่ละขั้นตอน และช่องว่างตั้งแต่สองช่องระหว่างแต่ละส่วน

Hint

A test with only one space between the pieces fails with "No keyword with name ... found". Most beginner errors in Robot are spaces.
