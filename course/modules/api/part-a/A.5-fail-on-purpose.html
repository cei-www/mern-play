Step A.5: Make a test fail on purpose

A test you have never seen fail is a test you cannot trust. Add a second test that checks the body of the health answer. Then you will break it on purpose and read the failure.

เทสต์ที่คุณไม่เคยเห็นมันล้ม เป็นเทสต์ที่ไว้ใจไม่ได้ เพิ่มเทสต์ที่สองที่ตรวจเนื้อหาของคำตอบ health แล้วคุณจะทำให้มันพังโดยตั้งใจและอ่านความล้มเหลว

Edit tests/01_health.robot (in the Explorer: api › tests › 01_health.robot).

Health Body Says Ok
    ${response}=    GET    ${BASE_URL}/api/health
    Should Be Equal    ${response.json()}[status]    ok
  1. Run robot --outputdir results tests. Both tests pass.
  2. Change the last word of the new test from ok to fine. Save and run again.
  3. Read the message: ok != fine. Open log.html and find the failing step.
  4. Change fine back to ok and run again.
  1. รัน robot --outputdir results tests เทสต์ทั้งสองผ่าน
  2. เปลี่ยนคำสุดท้ายของเทสต์ใหม่จาก ok เป็น fine บันทึกแล้วรันอีกครั้ง
  3. อ่านข้อความ: ok != fine เปิด log.html แล้วหา step ที่ล้ม
  4. เปลี่ยน fine กลับเป็น ok แล้วรันอีกครั้ง
Hint

${response.json()}[status] reads the key status from the JSON answer {"status": "ok"}.

Solution

In tests/01_health.robot:

Health Body Says Ok
    ${response}=    GET    ${BASE_URL}/api/health
    Should Be Equal    ${response.json()}[status]    ok
