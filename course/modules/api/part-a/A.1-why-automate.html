Step A.1: Why automate API tests

You tested the Task Manager by hand: you clicked, you called routes in Swagger, and you looked at the answer. That works once. After every change you would have to do it all again. An automated test is a small program that does it for you in seconds and tells you only pass or fail.

Every API test has three parts: a request (what you send), a response (what comes back) and an assertion (what you expect to see). For example: send GET /api/health, receive an answer, assert that the status is 200.

In this module you test the Task Manager API from the outside, with Robot Framework. You will not change the API. You will write only test files. The API under test is the finished reference API that runs inside this container on port 3001, with its own database taskapp_test.

คุณทดสอบ Task Manager ด้วยมือมาแล้ว: คลิก เรียก route ใน Swagger แล้วดูคำตอบ วิธีนี้ทำได้ครั้งเดียว ทุกครั้งที่แก้โค้ดต้องทำซ้ำทั้งหมด automated test คือโปรแกรมเล็ก ๆ ที่ทำให้แทนคุณในไม่กี่วินาที และบอกแค่ pass หรือ fail

เทสต์ API ทุกตัวมี 3 ส่วน: request (สิ่งที่ส่ง) response (สิ่งที่ตอบกลับ) และ assertion (สิ่งที่คาดหวังว่าจะเห็น) เช่น ส่ง GET /api/health รับคำตอบ แล้วยืนยันว่า status เป็น 200

ใน module นี้คุณทดสอบ Task Manager API จากภายนอก ด้วย Robot Framework คุณไม่แก้ API แต่เขียนเฉพาะไฟล์เทสต์ API ที่ถูกทดสอบคือ reference API ที่ทำงานอยู่ใน container นี้ที่พอร์ต 3001 พร้อมฐานข้อมูล taskapp_test ของมันเอง

This module runs in its own container, ws-robot, which is created but not started. Start it from your computer's terminal (not the editor's terminal), or press Start on ws-robot in Docker Desktop:

module นี้ทำงานใน container แยกชื่อ ws-robot ซึ่งสร้างไว้แต่ยังไม่ได้เปิด ให้เปิดจาก terminal ของเครื่องคุณ (ไม่ใช่ terminal ใน editor) หรือกดปุ่ม Start ของ ws-robot ใน Docker Desktop:

docker compose start ws-robot

When it is ready, the Robot tab shows a VS Code with the folder api. Before you automate anything, explore the reference API by hand. In Swagger the Servers list has "Reference API (module api)". Try listTasks and getTask there. You can also send requests from requests.http in the Explorer (api › requests.http): click Send Request above a line.

เมื่อพร้อมแล้ว tab Robot จะแสดง VS Code ที่มีโฟลเดอร์ api ก่อนจะทำอะไรอัตโนมัติ ให้ลองใช้ reference API ด้วยมือก่อน ใน Swagger รายการ Servers มี "Reference API (module api)" ลอง listTasks และ getTask ที่นั่น หรือส่ง request จาก requests.http ใน Explorer (api › requests.http) โดยคลิก Send Request เหนือบรรทัดนั้น

Hint

If the Robot tab says it cannot connect, wait half a minute after starting the container, then reload the tab. If docker compose start ws-robot complains that a network is not found, run docker compose --profile robot up -d --force-recreate ws-robot.
