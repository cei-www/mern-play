Step A.3: Your first test

Create a test that calls GET /api/health and asserts that the status code is 200. RequestsLibrary gives you the keyword GET; it returns a response object with status_code, headers and json(). Should Be Equal As Integers compares two numbers.

The test name is free text. Use exactly this name, because the check looks for it.

สร้างเทสต์ที่เรียก GET /api/health และยืนยันว่า status code เป็น 200 RequestsLibrary มี keyword GET ให้ ซึ่งคืน response object ที่มี status_code, headers และ json() ส่วน Should Be Equal As Integers เทียบตัวเลขสองค่า

ชื่อเทสต์เป็นข้อความอิสระ ให้ใช้ชื่อนี้ตามตัวอักษร เพราะการตรวจมองหาชื่อนี้

Create the file tests/01_health.robot (in the Explorer: api › tests › 01_health.robot) (right-click the folder in the Explorer, then New File).

*** Settings ***
Library    RequestsLibrary

*** Variables ***
${BASE_URL}    http://localhost:3001

*** Test Cases ***
Health Returns 200
    ${response}=    GET    ${BASE_URL}/api/health
    Should Be Equal As Integers    ${response.status_code}    200

Save the file. Nothing runs yet; the next step runs it.

บันทึกไฟล์ ยังไม่มีอะไรทำงาน step ถัดไปจะรันมัน

Hint

The file name starts with 01_ so the files run in a clear order. The URL is built from the variable: ${BASE_URL}/api/health.
