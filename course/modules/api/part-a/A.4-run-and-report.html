Step A.4: Run Robot and read the report

Open the terminal of the Robot tab (menu Terminal, New Terminal). Make sure you are in the folder api (the prompt ends with /workspace/api). Run:

เปิด terminal ของ tab Robot (เมนู Terminal แล้ว New Terminal) ตรวจให้แน่ใจว่าอยู่ในโฟลเดอร์ api (prompt ลงท้ายด้วย /workspace/api) แล้วรัน:

robot --outputdir results tests

Robot prints one line per test with PASS or FAIL, and writes three files to the folder results: output.xml (raw data), log.html (every step in detail) and report.html (a summary). Open the report in the Preview tab or press the button:

Robot พิมพ์หนึ่งบรรทัดต่อหนึ่งเทสต์พร้อม PASS หรือ FAIL และเขียนไฟล์สามไฟล์ลงโฟลเดอร์ results: output.xml (ข้อมูลดิบ) log.html (ทุกขั้นตอนอย่างละเอียด) และ report.html (สรุป) เปิดรายงานใน tab Preview หรือกดปุ่ม:

Open report.html

In the report, click the suite name and then the test name. In log.html every keyword is listed with the values it received. This is where you will look every time a test fails.

ในรายงาน คลิกชื่อ suite แล้วคลิกชื่อเทสต์ ใน log.html จะเห็นทุก keyword พร้อมค่าที่มันได้รับ นี่คือที่ที่คุณจะดูทุกครั้งที่เทสต์ล้ม

Hint

"No tests found" means the path is wrong or the file was not saved. If you ran robot from another folder, cd /workspace/api first.
