Step D.2: Variables and a resource file

Create a resource file. It has the same sections as a test file, but no Test Cases. It loads the libraries and holds the variables, so a test file only needs one line: Resource ../resources/api.resource.

สร้าง resource file มี section เหมือนไฟล์เทสต์ แต่ไม่มี Test Cases มันโหลด library และเก็บตัวแปร ไฟล์เทสต์จึงต้องการแค่บรรทัดเดียว: Resource ../resources/api.resource

Create the file resources/api.resource (in the Explorer: api › resources › api.resource) (right-click the folder in the Explorer, then New File).

*** Settings ***
Library    RequestsLibrary
Library    DatabaseLibrary
Library    Collections

*** Variables ***
${BASE_URL}    http://localhost:3001
${DB_NAME}     taskapp_test
${DB_USER}     robot
${DB_PASSWORD}    robot_pw
${DB_HOST}     db

The path ../resources/api.resource is relative to the test file: go up one folder (..), then into resources. Variables can be changed from the command line: robot --variable BASE_URL:http://localhost:3001 tests.

path ../resources/api.resource เป็น path เทียบกับไฟล์เทสต์: ขึ้นไปหนึ่งโฟลเดอร์ (..) แล้วเข้า resources ตัวแปรเปลี่ยนจากบรรทัดคำสั่งได้: robot --variable BASE_URL:http://localhost:3001 tests

Hint

Four variables are about the database (DB_NAME, DB_USER, DB_PASSWORD, DB_HOST) and one is the API address (BASE_URL). The extra library Collections is for later.
