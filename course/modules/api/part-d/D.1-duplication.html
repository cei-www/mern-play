Step D.1: The duplication problem

Look at your tests so far. The same pieces repeat: the base URL, the database connection, the lines that create a task, the lines that look it up in SQL. Copy and paste works until something changes. When the URL, the database name or the way to create a task changes, you must edit every file, and you will forget one.

Robot offers two tools against this:

  • a resource file (.resource): one place for the variables, the libraries and the keywords that many test files share;
  • your own keywords: a named group of steps that you can call like Create Task.

The goal of Part D: tests that read like sentences, and a change made in one place.

ดูเทสต์ที่คุณเขียนมาทั้งหมด จะเห็นส่วนเดิมซ้ำ ๆ: base URL, การเชื่อมต่อฐานข้อมูล, บรรทัดที่สร้าง task, บรรทัดที่ค้นหาใน SQL การ copy and paste ใช้ได้จนกว่าจะมีอะไรเปลี่ยน เมื่อ URL ชื่อฐานข้อมูล หรือวิธีสร้าง task เปลี่ยน คุณต้องแก้ทุกไฟล์ และจะลืมไปหนึ่งไฟล์

Robot มีเครื่องมือสองอย่างแก้ปัญหานี้:

  • resource file (.resource): ที่เดียวสำหรับตัวแปร library และ keyword ที่หลายไฟล์ใช้ร่วมกัน
  • keyword ของคุณเอง: กลุ่มขั้นตอนที่ตั้งชื่อ แล้วเรียกใช้ได้ เช่น Create Task
