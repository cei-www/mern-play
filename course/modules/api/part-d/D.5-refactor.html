Step D.5: Tests that read like sentences

Now the payoff. First add two more keywords to the resource file (Mark Task Done and Completed At Should Be Set). Then write a new test file that uses only keywords. Compare it with 03_tasks_create.robot: the same checks, with no URLs, no SQL and no dictionaries in sight.

The old files stay as they are: they still pass. In real work you would delete them after moving their tests.

ถึงตอนเก็บผล เริ่มจากเพิ่ม keyword อีกสองตัวในไฟล์ resource (Mark Task Done และ Completed At Should Be Set) แล้วเขียนไฟล์เทสต์ใหม่ที่ใช้แต่ keyword เทียบกับ 03_tasks_create.robot: ตรวจเรื่องเดียวกัน แต่ไม่มี URL, SQL หรือ dictionary ให้เห็นเลย

ไฟล์เก่ายังอยู่เหมือนเดิมและยังผ่าน งานจริงคุณจะลบทิ้งหลังย้ายเทสต์ไปแล้ว

Edit resources/api.resource (in the Explorer: api › resources › api.resource). First add the keywords at the end:

Mark Task Done
    [Arguments]    ${id}
    ${body}=    Create Dictionary    done=${True}
    ${response}=    PATCH    ${BASE_URL}/api/tasks/${id}/done    json=${body}
    Should Be Equal As Integers    ${response.status_code}    200

Completed At Should Be Set
    [Arguments]    ${id}
    ${rows}=    Query    SELECT completed_at IS NOT NULL FROM tasks WHERE id = ${id}
    Should Be Equal As Integers    ${rows}[0][0]    1

Create the file tests/05_tasks_clean.robot (in the Explorer: api › tests › 05_tasks_clean.robot) (right-click the folder in the Explorer, then New File). Then the tests:

*** Settings ***
Resource    ../resources/api.resource
Suite Setup    Connect To Test Database
Suite Teardown    Disconnect From All Databases
Test Teardown    Delete Test Tasks

*** Test Cases ***
New Task Is Stored
    ${id}=    Create Task    Robot clean task    priority=${3}
    Task Should Exist    ${id}

Done Task Has A Completion Time
    ${id}=    Create Task    Robot clean done
    Mark Task Done    ${id}
    Completed At Should Be Set    ${id}
robot --outputdir results tests
Hint

The test file only loads the resource; it does not need Library lines. The setup keyword Connect To Test Database and the teardown Delete Test Tasks come from the resource.
