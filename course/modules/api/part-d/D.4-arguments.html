Step D.4: Arguments and return values

A keyword can take arguments ([Arguments] ${title} ${priority}=${2}: the second has a default) and give back a value with RETURN. Create Task sends the request, checks for 201 and returns the new id. Task Should Exist takes an id and checks the database.

Using it looks like this: ${id}= Create Task Robot demo priority=${3}.

keyword รับ argument ได้ ([Arguments] ${title} ${priority}=${2}: ตัวที่สองมีค่าเริ่มต้น) และส่งค่ากลับด้วย RETURN Create Task ส่ง request ตรวจว่าได้ 201 และคืน id ใหม่ Task Should Exist รับ id แล้วตรวจฐานข้อมูล

การเรียกใช้เป็นแบบนี้: ${id}= Create Task Robot demo priority=${3}

Edit resources/api.resource (in the Explorer: api › resources › api.resource). Add at the end of the file.

Create Task
    [Arguments]    ${title}    ${priority}=${2}
    ${body}=    Create Dictionary    title=${title}    priority=${priority}
    ${response}=    POST    ${BASE_URL}/api/tasks    json=${body}
    Should Be Equal As Integers    ${response.status_code}    201
    RETURN    ${response.json()}[id]

Task Should Exist
    [Arguments]    ${id}
    ${rows}=    Query    SELECT COUNT(*) FROM tasks WHERE id = ${id}
    Should Be Equal As Integers    ${rows}[0][0]    1
Hint

A name with variables must be written the same way where you use it: argument names such as ${title} live only inside the keyword.
