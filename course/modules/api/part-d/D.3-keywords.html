Step D.3: Your own keywords

A keyword is defined in a *** Keywords *** section: the name on the left edge, the steps indented under it. Add two small ones to the resource file: one that connects to the test database and one that deletes the tasks the tests created. Their names say what they do, so the tests will read well.

keyword นิยามใน section *** Keywords ***: ชื่ออยู่ชิดซ้าย ขั้นตอนเยื้องเข้าไปใต้ชื่อ เพิ่มสองตัวเล็ก ๆ ในไฟล์ resource: ตัวหนึ่งเชื่อมต่อฐานข้อมูลทดสอบ อีกตัวลบ task ที่เทสต์สร้าง ชื่อของมันบอกว่าทำอะไร เทสต์จึงอ่านง่าย

Edit resources/api.resource (in the Explorer: api › resources › api.resource). Add at the end of the file.

*** Keywords ***
Connect To Test Database
    Connect To Database    pymysql    db_name=${DB_NAME}    db_user=${DB_USER}    db_password=${DB_PASSWORD}    db_host=${DB_HOST}    db_port=3306

Delete Test Tasks
    Execute Sql String    DELETE FROM tasks WHERE title LIKE 'Robot %'
Hint

The first line of the file is still *** Settings ***. The new section *** Keywords *** goes below the variables.
