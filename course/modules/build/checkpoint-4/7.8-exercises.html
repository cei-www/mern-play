Exercise 7 (easier): GET /api/stats/group/:id

Add the route GET /api/stats/group/1. It answers { "name": "Work", "total": 6, "done": 3 } for that group (the real numbers of the database). When the group does not exist, answer 404 with { "error": "Group not found" }. Put it under the stats router you wrote in Checkpoint 1.

เพิ่ม route GET /api/stats/group/1 ให้ตอบ { "name": "Work", "total": 6, "done": 3 } ของ group นั้น (ตัวเลขจริงของฐานข้อมูล) ถ้าไม่มี group ให้ตอบ 404 พร้อม { "error": "Group not found" } ใส่ใน router ของ stats ที่คุณเขียนไว้ใน Checkpoint 1

Edit server/routes/stats.js (in the Explorer: build › server › routes › stats.js). Write the code between the comments @tutorial:begin exercise-7-group-stats and @tutorial:end exercise-7-group-stats.

Hint

Two queries: one for the group name (404 when there is no row), one for COUNT(*) and SUM(done) of the tasks with that group_id.

Solution

In server/routes/stats.js, between the comments of exercise-7-group-stats:

router.get('/group/:id', async (req, res, next) => {
  const id = Number(req.params.id);
  if (!Number.isInteger(id)) return res.status(400).json({ error: 'id must be a whole number' });
  try {
    const [[group]] = await db.query('SELECT name FROM task_groups WHERE id = ?', [id]);
    if (!group) return res.status(404).json({ error: 'Group not found' });
    const [[totals]] = await db.query(
      'SELECT COUNT(*) AS total, CAST(COALESCE(SUM(done), 0) AS UNSIGNED) AS done FROM tasks WHERE group_id = ?',
      [id],
    );
    res.json({ name: group.name, total: totals.total, done: totals.done });
  } catch (err) {
    next(err);
  }
});

Exercise 8 (harder): RetryButton

Write the component RetryButton. When loading the tasks fails, the page shows it. It is a button that says Try again and calls the prop onRetry when clicked. To see it, stop your API: add a typo to server/app.js so the server crashes, or ask for a wrong URL temporarily.

เขียน component RetryButton เมื่อโหลด task ล้มเหลว หน้าเว็บจะแสดงมัน เป็นปุ่มที่เขียนว่า Try again และเรียก prop onRetry เมื่อคลิก หากอยากเห็น ให้ทำให้ API ล่ม: ใส่ตัวพิมพ์ผิดใน server/app.js ให้เซิร์ฟเวอร์ crash หรือขอ URL ผิดชั่วคราว
