Step 1.8: Show the tasks in React

The API works. Now the page must call it. The component TaskList does three things:

  • useState keeps the tasks, a loading flag and an error message.
  • useEffect calls fetch('/api/tasks') when the component appears (and again when query or reloadKey change).
  • It draws the loading text, the error, an empty message or the list. Each row is a ready-made TaskItem.

The Vite server forwards every /api request to Express, so the page can use a short URL.

API ทำงานแล้ว ตอนนี้หน้าเว็บต้องเรียกใช้ component TaskList ทำ 3 อย่าง:

  • useState เก็บ tasks, flag loading และข้อความ error
  • useEffect เรียก fetch('/api/tasks') เมื่อ component ปรากฏ (และเรียกอีกเมื่อ query หรือ reloadKey เปลี่ยน)
  • แสดงข้อความ loading, error, ข้อความว่าง หรือรายการ แต่ละแถวใช้ TaskItem ที่เตรียมไว้ให้แล้ว

เซิร์ฟเวอร์ Vite ส่งทุก request ที่ขึ้นต้นด้วย /api ไปให้ Express หน้าเว็บจึงใช้ URL สั้น ๆ ได้

Edit client/src/components/TaskList.jsx. Write the code between the comments @tutorial:begin s1-8-task-list and @tutorial:end s1-8-task-list, inside the function.

const [tasks, setTasks] = useState([]);
const [loading, setLoading] = useState(true);
const [error, setError] = useState('');

useEffect(() => {
  setLoading(true);
  fetch(`/api/tasks${query}`)
    .then((res) => {
      if (!res.ok) throw new Error(`The server answered ${res.status}`);
      return res.json();
    })
    .then((data) => {
      setTasks(data);
      setError('');
    })
    .catch((err) => setError(err.message))
    .finally(() => setLoading(false));
}, [query, reloadKey]);

if (loading) return <p>Loading...</p>;
if (error) return <p role="alert">Could not load the tasks: {error}</p>;
if (tasks.length === 0) return <p>No tasks yet.</p>;

return (
  <ul className="task-list">
    {tasks.map((task) => (
      <TaskItem key={task.id} task={task} onChanged={onChanged} />
    ))}
  </ul>
);
