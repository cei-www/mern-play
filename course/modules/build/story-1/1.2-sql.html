Step 1.2: Read tasks with SQL

The API gets its data with SQL. Try the queries by hand first. Open the Database tab, press Login, choose SQL command in the menu, paste a query and press Execute.

All tasks:

API ดึงข้อมูลด้วย SQL ลองรัน query ด้วยมือก่อน เปิด tab Database กด Login เลือก SQL command ในเมนู วาง query แล้วกด Execute

ทุก task:

SELECT * FROM tasks;

Only the open tasks, newest first:

เฉพาะ task ที่ยังไม่เสร็จ เรียงจากใหม่ไปเก่า:

SELECT id, title, priority
FROM tasks
WHERE done = 0
ORDER BY created_at DESC;

Each task knows its group only by a number (group_id). A LEFT JOIN brings in the group name. "Left" means a task without a group is kept, with NULL as the name. This is the query your route will use:

แต่ละ task รู้จัก group เป็นแค่ตัวเลข (group_id) การใช้ LEFT JOIN จะดึงชื่อ group มาด้วย คำว่า "left" หมายความว่า task ที่ไม่มี group ยังอยู่ในผลลัพธ์ โดยชื่อเป็น NULL นี่คือ query ที่ route ของคุณจะใช้:

SELECT t.*, g.name AS group_name
FROM tasks t
LEFT JOIN task_groups g ON g.id = t.group_id
ORDER BY t.created_at DESC;

The table is called task_groups and not groups, because GROUPS is a reserved word in MySQL 8.

ตารางชื่อ task_groups ไม่ใช่ groups เพราะ GROUPS เป็นคำสงวนใน MySQL 8

Hint

If the Database tab asks for a password it is already filled in. Press Login. You can only read in this database from here.
