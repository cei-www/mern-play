Step 1.7: Try the route

You now have the route. Look at it in three ways. They all call the same URL.

  1. The browser: open /api/tasks in Preview. You see the raw JSON.
  2. A request file: open server/requests.http in the Editor (Explorer: build › server › requests.http) and click Send Request above the line GET http://localhost:3000/api/tasks. The answer opens beside it with the status and the headers.
  3. Swagger: run listTasks. In step 0.6 it answered 404. Now it answers 200 with your rows.

ตอนนี้คุณมี route แล้ว ลองดูได้ 3 วิธี ซึ่งเรียก URL เดียวกันทั้งหมด

  1. เบราว์เซอร์: เปิด /api/tasks ใน Preview จะเห็น JSON ดิบ
  2. ไฟล์ request: เปิด server/requests.http ใน Editor (Explorer: build › server › requests.http) แล้วคลิก Send Request เหนือบรรทัด GET http://localhost:3000/api/tasks คำตอบจะเปิดข้าง ๆ พร้อม status และ header
  3. Swagger: รัน listTasks ใน step 0.6 ได้ 404 ตอนนี้ได้ 200 พร้อมแถวของคุณ

Open /api/tasks

Look at one task in the answer. Which keys does it have? Find group_name. Which tasks have null there, and why?

ดู task หนึ่งชิ้นในคำตอบ มี key อะไรบ้าง? หา group_name task ไหนมีค่าเป็น null และเพราะอะไร?

Hint

Tasks that have no group (group_id is null) get null as group_name, because of the LEFT JOIN.
