Step 1.5: Mount the tasks router

The file server/routes/tasks.js already creates a Router and exports it, but it has no routes yet. Tell the app to use it under the path /api/tasks.

ไฟล์ server/routes/tasks.js สร้าง Router และ export ไว้แล้ว แต่ยังไม่มี route เลย บอกให้แอปใช้มันที่ path /api/tasks

Edit server/app.js (in the Explorer: build › server › app.js). Write the code between the comments @tutorial:begin s1-5-mount-tasks and @tutorial:end s1-5-mount-tasks.

const tasksRouter = require('./routes/tasks');
app.use('/api/tasks', tasksRouter);

require loads the other file. app.use(path, router) adds a prefix to every route of that router. Nothing answers /api/tasks yet, because the router is empty: that comes next.

require โหลดไฟล์อื่นเข้ามา app.use(path, router) เติม prefix ให้ทุก route ของ router นั้น ตอนนี้ยังไม่มีอะไรตอบที่ /api/tasks เพราะ router ยังว่าง ซึ่งเป็น step ถัดไป

Hint

The path in app.use starts with /api. The router file name has no .js in require('./routes/tasks').

Solution

In server/app.js, between the comments of s1-5-mount-tasks:

const tasksRouter = require('./routes/tasks');
app.use('/api/tasks', tasksRouter);
