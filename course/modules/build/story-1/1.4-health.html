Step 1.4: Add GET /api/health

Start with the smallest route: a health check that tells the world the API is alive. It does not use the database.

เริ่มจาก route ที่เล็กที่สุด คือ health check ที่บอกว่า API ยังทำงานอยู่ โดยไม่ต้องใช้ฐานข้อมูล

Edit server/app.js (in the Explorer: build › server › app.js). Write the code between the comments @tutorial:begin s1-4-health and @tutorial:end s1-4-health.

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' });
});

Save the file. After a second, open the route in Preview or call it in Swagger:

บันทึกไฟล์ รอสักครู่ แล้วเปิด route ใน Preview หรือเรียกใน Swagger:

Open /api/health
