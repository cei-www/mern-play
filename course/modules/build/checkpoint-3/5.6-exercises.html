Exercise 5 (easier): GET /api/high-priority

Write GET /api/high-priority. It answers the tasks with priority 3 that are not done yet, ordered by due date (the earliest first; tasks without a due date last). Include group_name.

เขียน GET /api/high-priority ให้ตอบ task ที่ priority เป็น 3 และยังไม่เสร็จ เรียงตามวันครบกำหนด (ใกล้สุดก่อน task ที่ไม่มีวันครบกำหนดอยู่ท้ายสุด) พร้อม group_name

Edit server/routes/highPriority.js (in the Explorer: build › server › routes › highPriority.js). Write the code between the comments @tutorial:begin exercise-5-high-priority and @tutorial:end exercise-5-high-priority.

Hint

ORDER BY t.due_date IS NULL, t.due_date puts tasks without a due date last. The file is already connected at /api/high-priority.

Solution

In server/routes/highPriority.js, between the comments of exercise-5-high-priority:

router.get('/', async (req, res, next) => {
  try {
    const [rows] = await db.query(
      `SELECT t.*, g.name AS group_name
       FROM tasks t
       LEFT JOIN task_groups g ON g.id = t.group_id
       WHERE t.priority = 3 AND t.done = 0
       ORDER BY t.due_date IS NULL, t.due_date, t.id`,
    );
    res.json(rows);
  } catch (err) {
    next(err);
  }
});
