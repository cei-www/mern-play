Step 3.3: PATCH /api/tasks/:id/done

The route reads the id from the path with req.params.id and the flag from the body. It checks both, runs the UPDATE and answers with the updated task.

  • Number.isInteger(id) rejects an id such as abc with 400.
  • The flag must be a real true or false, not the text "true".
  • After the update the route reads the task again. If there is no such task the answer is 404. (affectedRows is another way to find out; reading again also gives you the data to send back.)

route อ่าน id จาก path ด้วย req.params.id และ flag จาก body ตรวจทั้งสอง รัน UPDATE แล้วตอบด้วย task ที่อัปเดตแล้ว

  • Number.isInteger(id) ปฏิเสธ id อย่าง abc ด้วย 400
  • flag ต้องเป็น true หรือ false จริง ๆ ไม่ใช่ข้อความ "true"
  • หลังอัปเดต route อ่าน task อีกครั้ง ถ้าไม่มี task นั้นให้ตอบ 404 (affectedRows เป็นอีกวิธีที่รู้ได้ แต่การอ่านซ้ำก็ได้ข้อมูลไว้ตอบกลับด้วย)

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s3-3-set-done and @tutorial:end s3-3-set-done.

router.patch('/:id/done', async (req, res, next) => {
  const id = Number(req.params.id);
  if (!Number.isInteger(id)) return res.status(400).json({ error: 'id must be a whole number' });
  if (typeof req.body?.done !== 'boolean') return res.status(400).json({ error: 'done must be true or false' });
  try {
    await db.query('UPDATE tasks SET done = ?, completed_at = IF(?, NOW(), NULL) WHERE id = ?', [
      req.body.done ? 1 : 0,
      req.body.done ? 1 : 0,
      id,
    ]);
    const task = await findTask(id);
    if (!task) return res.status(404).json({ error: 'Task not found' });
    res.json(task);
  } catch (err) {
    next(err);
  }
});

Save the file. In Swagger run setTaskDone with an id from your list and { "done": true }. Then try an id that does not exist, such as 999999, and read the 404.

บันทึกไฟล์ ใน Swagger รัน setTaskDone ด้วย id จากรายการของคุณและ { "done": true } จากนั้นลอง id ที่ไม่มีอยู่ เช่น 999999 และอ่านคำตอบ 404

Hint

The two placeholders for the flag in the UPDATE get the same value (done = ? and IF(?, ...)). Check the order of the values in the array: flag, flag, id.
