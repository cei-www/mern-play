Step 3.2: Update a row with SQL

UPDATE changes rows. Always write a WHERE: without it every row changes. Try in the Database tab (SQL command), using the id of your test row from Story 2:

UPDATE แก้แถว ต้องเขียน WHERE เสมอ ถ้าไม่มี ทุกแถวจะถูกแก้ ลองใน tab Database (SQL command) โดยใช้ id ของแถวทดสอบจาก Story 2:

UPDATE tasks SET done = 1, completed_at = NOW() WHERE title = 'Try INSERT';
SELECT id, title, done, completed_at FROM tasks WHERE title = 'Try INSERT';

UPDATE tasks SET done = 0, completed_at = NULL WHERE title = 'Try INSERT';

NOW() is the current time and NULL means "no value". The route will do the same with one query: completed_at = IF(?, NOW(), NULL) picks the time when the flag is 1 and NULL when it is 0.

NOW() คือเวลาปัจจุบัน และ NULL หมายถึง "ไม่มีค่า" route จะทำแบบเดียวกันด้วย query เดียว: completed_at = IF(?, NOW(), NULL) เลือกเวลาเมื่อ flag เป็น 1 และเลือก NULL เมื่อเป็น 0

Hint

If you forget the WHERE, run reset-db in the terminal to get the sample data back.
