Step 3.4: The checkbox

Each row (TaskItem) gets a checkbox. When it changes, the page calls PATCH and then asks the list to reload with onChanged().

This is a safe, simple way: the page waits for the server and then shows what the server says. (A faster-feeling way, the optimistic update, changes the screen first and corrects it if the server refuses. You can try it as your own experiment.)

แต่ละแถว (TaskItem) จะมี checkbox เมื่อเปลี่ยนค่า หน้าเว็บเรียก PATCH แล้วสั่งให้รายการโหลดใหม่ด้วย onChanged()

วิธีนี้ปลอดภัยและง่าย: หน้าเว็บรอ server แล้วแสดงตามที่ server บอก (วิธีที่รู้สึกเร็วกว่าคือ optimistic update ซึ่งเปลี่ยนหน้าจอก่อนแล้วแก้กลับถ้า server ปฏิเสธ ลองทำเองเป็นการทดลองได้)

Edit client/src/components/TaskItem.jsx (in the Explorer: build › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s3-4-done-checkbox and @tutorial:end s3-4-done-checkbox (they look like {/* ... */} here, because they sit inside JSX).

<input
  type="checkbox"
  checked={task.done === 1}
  aria-label={`Mark "${task.title}" as done`}
  onChange={(event) =>
    fetch(`/api/tasks/${task.id}/done`, {
      method: 'PATCH',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ done: event.target.checked }),
    }).then(() => onChanged?.())
  }
/>
