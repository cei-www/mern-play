Step 4.3: Mount the groups router

The file server/routes/groups.js already creates a router. Mount it at /api/groups, the same way you mounted the tasks router in step 1.5.

ไฟล์ server/routes/groups.js สร้าง router ไว้แล้ว นำมาต่อที่ /api/groups แบบเดียวกับที่ต่อ router ของ tasks ใน step 1.5

Edit server/app.js (in the Explorer: build › server › app.js). Write the code between the comments @tutorial:begin s4-3-mount-groups and @tutorial:end s4-3-mount-groups.

const groupsRouter = require('./routes/groups');
app.use('/api/groups', groupsRouter);
Hint

Same two lines as step 1.5, with groups instead of tasks.
