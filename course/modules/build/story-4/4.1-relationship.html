Step 4.1: Groups and tasks

As a user, I want to put my tasks into groups such as Work and Home, so that I can find them quickly.

A group is a row in the table task_groups. A task points to its group with the number group_id. This is a foreign key: MySQL refuses a group_id that does not exist. The column can be NULL, so a task may have no group.

One group has many tasks (a one-to-many relationship). You already used the join in Story 1 to get group_name. This story adds the groups themselves: list them with the number of tasks in each, create new ones, and choose one in the page.
