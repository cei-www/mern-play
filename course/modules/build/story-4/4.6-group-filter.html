Step 4.6: Choose a group in the page

GroupFilter shows a button for All and one for every group, with its count, and a + Group button. It reads /api/groups when it appears and again when the page reloads (reloadKey).

The selected group has two jobs: a task you add goes into it (Story 2 already sends group_id), and in Story 5 it will filter the list. The list does not change yet when you click a group. That is Story 5.

GroupFilter แสดงปุ่ม All และปุ่มของแต่ละ group พร้อมจำนวน task กับปุ่ม + Group มันอ่าน /api/groups เมื่อปรากฏ และอ่านอีกครั้งเมื่อหน้าโหลดใหม่ (reloadKey)

group ที่เลือกมี 2 หน้าที่: task ที่คุณเพิ่มจะไปอยู่ใน group นั้น (Story 2 ส่ง group_id อยู่แล้ว) และใน Story 5 มันจะกรองรายการ ตอนนี้การคลิก group ยังไม่ทำให้รายการเปลี่ยน นั่นคือ Story 5

Edit client/src/components/GroupFilter.jsx (in the Explorer: build › client › src › components › GroupFilter.jsx). Write the code between the comments @tutorial:begin s4-6-group-filter and @tutorial:end s4-6-group-filter, inside the function.

const [groups, setGroups] = useState([]);
const [version, setVersion] = useState(0);

useEffect(() => {
  fetch('/api/groups')
    .then((res) => res.json())
    .then(setGroups)
    .catch(() => setGroups([]));
}, [reloadKey, version]);

async function addGroup() {
  const name = window.prompt('Name of the new group');
  if (!name) return;
  const res = await fetch('/api/groups', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name }),
  });
  if (!res.ok) window.alert((await res.json()).error);
  setVersion((v) => v + 1);
}

return (
  <div className="groups" role="group" aria-label="Groups">
    <button type="button" className={value === null ? 'active' : ''} onClick={() => onChange(null)}>
      All
    </button>
    {groups.map((group) => (
      <button
        key={group.id}
        type="button"
        className={value === group.id ? 'active' : ''}
        style={{ borderColor: group.color }}
        onClick={() => onChange(group.id)}
      >
        {group.name} ({group.task_count})
      </button>
    ))}
    <button type="button" onClick={addGroup}>
      + Group
    </button>
  </div>
);
