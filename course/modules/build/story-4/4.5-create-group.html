Step 4.5: POST /api/groups

Creating a group needs a name (1 to 50 characters) and an optional colour such as #0d6efd. Validate both and answer 400 with a clear message, otherwise insert and answer 201 with the new group (its count of tasks is 0).

การสร้าง group ต้องมีชื่อ (1 ถึง 50 ตัวอักษร) และสีเป็นทางเลือก เช่น #0d6efd ตรวจทั้งสองอย่างและตอบ 400 พร้อมข้อความที่ชัดเจน ถ้าผ่านก็ insert แล้วตอบ 201 พร้อม group ใหม่ (จำนวน task เป็น 0)

Edit server/routes/groups.js (in the Explorer: build › server › routes › groups.js). Write the code between the comments @tutorial:begin s4-5-create-group and @tutorial:end s4-5-create-group.

router.post('/', async (req, res, next) => {
  const name = typeof req.body?.name === 'string' ? req.body.name.trim() : '';
  if (name.length < 1 || name.length > 50) return res.status(400).json({ error: 'name is required (1-50 characters)' });
  const color = req.body.color ?? '#6c757d';
  if (!/^#[0-9a-fA-F]{6}$/.test(color)) return res.status(400).json({ error: 'color must look like #0d6efd' });
  try {
    const [result] = await db.query('INSERT INTO task_groups (user_id, name, color) VALUES (?, ?, ?)', [USER_ID, name, color]);
    res.status(201).json({ id: result.insertId, name, color, task_count: 0 });
  } catch (err) {
    next(err);
  }
});

Hint

A regular expression can check a colour: /^#[0-9a-fA-F]{6}$/.test(color). Use ?? '#6c757d' to give a default when the client sends none.

Solution

In server/routes/groups.js, between the comments of s4-5-create-group:
