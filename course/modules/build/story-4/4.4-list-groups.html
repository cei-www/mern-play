Step 4.4: GET /api/groups

The route runs the query of step 4.2 and sends the rows. The constant USER_ID at the top of the file is the one user of this app (there is no login).

route รัน query จาก step 4.2 แล้วส่งแถวที่ได้กลับ ค่าคงที่ USER_ID ที่ต้นไฟล์คือผู้ใช้เพียงคนเดียวของแอปนี้ (ไม่มีการ login)

Edit server/routes/groups.js (in the Explorer: build › server › routes › groups.js). Write the code between the comments @tutorial:begin s4-4-list-groups and @tutorial:end s4-4-list-groups.

router.get('/', async (req, res, next) => {
  try {
    const [rows] = await db.query(
      `SELECT g.id, g.name, g.color, COUNT(t.id) AS task_count
       FROM task_groups g
       LEFT JOIN tasks t ON t.group_id = g.id
       WHERE g.user_id = ?
       GROUP BY g.id
       ORDER BY g.name`,
      [USER_ID],
    );
    res.json(rows);
  } catch (err) {
    next(err);
  }
});

Hint

It is the same pattern as step 1.6: try, await db.query(sql, [values]), res.json(rows), catch with next(err). The value for the ? is USER_ID in an array.

Solution

In server/routes/groups.js, between the comments of s4-4-list-groups:
