Step 4.2: Count with GROUP BY

How many tasks does each group have? GROUP BY makes one result row per group and COUNT counts inside each. Run this in the Database tab:

แต่ละ group มีกี่ task? GROUP BY ทำให้ผลลัพธ์หนึ่งแถวต่อหนึ่ง group และ COUNT นับในแต่ละกลุ่ม รันใน tab Database:

SELECT g.id, g.name, g.color, COUNT(t.id) AS task_count
FROM task_groups g
LEFT JOIN tasks t ON t.group_id = g.id
GROUP BY g.id
ORDER BY g.name;

Why LEFT JOIN and COUNT(t.id)? A group without tasks must still appear, with a count of 0. COUNT(t.id) skips the empty NULL that the join makes for it. Try creating a group in the task_groups table and see that it shows 0.

ทำไมใช้ LEFT JOIN และ COUNT(t.id)? group ที่ไม่มี task ต้องยังปรากฏและมีจำนวนเป็น 0 COUNT(t.id) ไม่นับ NULL ที่ join สร้างขึ้นให้ ลองสร้าง group ใหม่ในตาราง task_groups แล้วดูว่าแสดง 0

Hint

With a plain JOIN (inner join) a group that has no tasks disappears from the result.
