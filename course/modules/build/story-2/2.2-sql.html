Step 2.2: Insert a row with SQL

INSERT adds a row. Open the Database tab, press Login, choose SQL command and run:

INSERT เพิ่มแถวใหม่ เปิด tab Database กด Login เลือก SQL command แล้วรัน:

INSERT INTO tasks (user_id, group_id, title, priority, due_date)
VALUES (1, NULL, 'Try INSERT', 2, '2030-01-31');

SELECT * FROM tasks ORDER BY id DESC LIMIT 1;

You did not give an id, done or created_at. The table fills them in: id is AUTO_INCREMENT (the next number), done starts at 0 and created_at is the current time.

In the route you will not paste the title into the SQL text. You write a ? and give the value separately. This is a placeholder, and it is what stops SQL injection: the value can never turn into SQL.

คุณไม่ได้ใส่ id, done หรือ created_at ตารางเติมให้เอง: id เป็น AUTO_INCREMENT (เลขถัดไป) done เริ่มที่ 0 และ created_at เป็นเวลาปัจจุบัน

ใน route คุณจะไม่นำ title ไปต่อเป็นข้อความ SQL แต่เขียน ? แล้วส่งค่าแยกต่างหาก นี่คือ placeholder ซึ่งป้องกัน SQL injection: ค่าที่ส่งมาจะไม่มีทางกลายเป็นคำสั่ง SQL

This test row stays in your table. It is harmless, and reset-db removes it.

แถวทดสอบนี้จะอยู่ในตาราง ไม่เป็นอันตราย และ reset-db จะลบออก

Hint

If MySQL says the column count does not match, count the names after INSERT INTO tasks and the values after VALUES: there must be the same number.
