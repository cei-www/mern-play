Step 2.5: The form in React

The component TaskForm is a controlled form: each input shows a value kept in state and updates it on every change. On submit it sends the data with fetch, shows the server's error if there is one, and tells the page to reload the list with onCreated().

  • event.preventDefault() stops the browser from reloading the page.
  • A date input gives an empty text when it is empty. The code sends null instead (dueDate || null).
  • A new task goes into the selected group (the prop groupId, or none).

component TaskForm เป็น controlled form: แต่ละ input แสดงค่าที่เก็บใน state และอัปเดตทุกครั้งที่เปลี่ยน ตอน submit จะส่งข้อมูลด้วย fetch แสดง error จาก server ถ้ามี และบอกหน้าเว็บให้โหลดรายการใหม่ด้วย onCreated()

  • event.preventDefault() ไม่ให้เบราว์เซอร์ reload หน้า
  • input วันที่ที่ว่างให้ข้อความว่าง โค้ดจึงส่ง null แทน (dueDate || null)
  • task ใหม่ไปอยู่ใน group ที่เลือก (prop groupId หรือไม่มี group)

Edit client/src/components/TaskForm.jsx (in the Explorer: build › client › src › components › TaskForm.jsx). Write the code between the comments @tutorial:begin s2-5-task-form and @tutorial:end s2-5-task-form, inside the function.

const [title, setTitle] = useState('');
const [priority, setPriority] = useState(2);
const [dueDate, setDueDate] = useState('');
const [error, setError] = useState('');

async function handleSubmit(event) {
  event.preventDefault();
  const res = await fetch('/api/tasks', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title, priority, due_date: dueDate || null, group_id: groupId }),
  });
  if (!res.ok) {
    setError((await res.json()).error);
    return;
  }
  setTitle('');
  setDueDate('');
  setError('');
  onCreated?.();
}

return (
  <form className="task-form" onSubmit={handleSubmit}>
    <input value={title} onChange={(e) => setTitle(e.target.value)} placeholder="What needs doing?" aria-label="Title" />
    <select value={priority} onChange={(e) => setPriority(Number(e.target.value))} aria-label="Priority">
      <option value={1}>low</option>
      <option value={2}>medium</option>
      <option value={3}>high</option>
    </select>
    <input type="date" value={dueDate} onChange={(e) => setDueDate(e.target.value)} aria-label="Due date" />
    <button type="submit">Add</button>
    {error && <p role="alert">{error}</p>}
  </form>
);
