Step 2.4: POST /api/tasks

Now the route. It validates, runs the INSERT with placeholders and answers 201 Created with the task that was stored.

  • req.body is the JSON the client sent. The line app.use(express.json()) in app.js reads it for you.
  • The ? placeholders get their values from the array. The array order is the order of the question marks.
  • result.insertId is the id that MySQL created. Use it to read the task back with the group name.
  • A group id that does not exist makes MySQL refuse the row (foreign key). The route turns this into a 400.

ถึงเวลาทำ route มันตรวจข้อมูล รัน INSERT ด้วย placeholder แล้วตอบ 201 Created พร้อม task ที่เก็บแล้ว

  • req.body คือ JSON ที่ client ส่งมา บรรทัด app.use(express.json()) ใน app.js อ่านให้แล้ว
  • placeholder ? รับค่าจาก array ลำดับใน array คือลำดับของเครื่องหมายคำถาม
  • result.insertId คือ id ที่ MySQL สร้างให้ ใช้อ่าน task กลับมาพร้อมชื่อ group
  • ถ้า group id ไม่มีอยู่จริง MySQL จะปฏิเสธแถว (foreign key) และ route แปลงเป็น 400

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s2-4-create-task and @tutorial:end s2-4-create-task.

router.post('/', async (req, res, next) => {
  const { error, value } = validateTask(req.body);
  if (error) return res.status(400).json({ error });
  try {
    const [result] = await db.query(
      'INSERT INTO tasks (user_id, group_id, title, priority, due_date) VALUES (?, ?, ?, ?, ?)',
      [USER_ID, value.groupId, value.title, value.priority, value.dueDate],
    );
    res.status(201).json(await findTask(result.insertId));
  } catch (err) {
    if (err.code === 'ER_NO_REFERENCED_ROW_2') return res.status(400).json({ error: 'group_id does not exist' });
    next(err);
  }
});

Save the file. Try it in Swagger: press Try it out, use the example body and Execute. Then send a body with an empty title and read the 400 answer.

Hint

The route has three outcomes: 400 when validation fails (answer with return), 201 when the insert works, and next(err) for other database errors. The code ER_NO_REFERENCED_ROW_2 means the group does not exist.
