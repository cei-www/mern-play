Step 2.3: Validate the input

Never trust what a client sends. validateTask(body) checks the body and returns either { error } with a message for the caller, or { value } with clean values. The route will use it in the next step.

The rules: a title of 1 to 100 characters (spaces at the ends are cut off), a priority of 1, 2 or 3 (default 2), a due date written like 2030-01-31 or nothing, and a group id that is a whole number or nothing.

อย่าเชื่อสิ่งที่ client ส่งมา validateTask(body) ตรวจ body แล้วคืนค่าเป็น { error } พร้อมข้อความสำหรับผู้เรียก หรือ { value } พร้อมค่าที่สะอาดแล้ว step ถัดไป route จะนำไปใช้

กติกา: title ยาว 1 ถึง 100 ตัวอักษร (ตัดช่องว่างหัวท้าย) priority เป็น 1, 2 หรือ 3 (ค่าเริ่มต้น 2) วันที่ครบกำหนดเขียนแบบ 2030-01-31 หรือไม่ใส่ก็ได้ และ group id เป็นจำนวนเต็มหรือไม่ใส่ก็ได้

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s2-3-validate and @tutorial:end s2-3-validate.

// Checks a task from the request body. Returns { error } or { value }.
function validateTask(body) {
  const title = typeof body?.title === 'string' ? body.title.trim() : '';
  if (title.length < 1 || title.length > 100) return { error: 'title is required (1-100 characters)' };

  const priority = body.priority === undefined ? 2 : body.priority;
  if (![1, 2, 3].includes(priority)) return { error: 'priority must be 1, 2 or 3' };

  const dueDate = body.due_date ?? null;
  if (dueDate !== null && !/^\d{4}-\d{2}-\d{2}$/.test(dueDate)) return { error: 'due_date must look like 2026-12-31' };

  const groupId = body.group_id ?? null;
  if (groupId !== null && !Number.isInteger(groupId)) return { error: 'group_id must be a whole number' };

  return { value: { title, priority, dueDate, groupId } };
}

Save the file. Nothing calls this function yet, so there is nothing to see. The next step uses it.

Hint
