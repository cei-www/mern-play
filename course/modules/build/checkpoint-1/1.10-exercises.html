Checkpoint 1: two exercises

About 15 minutes. Both exercises are optional: skipping them does not block the next stories. Try first, then open the hint, and only then the solution.

ใช้เวลาประมาณ 15 นาที โจทย์ทั้งสองข้อเป็นทางเลือก ข้ามได้โดยไม่กระทบ story ถัดไป ลองทำเองก่อน แล้วค่อยเปิด hint และเปิด solution เป็นลำดับสุดท้าย

Exercise 1 (easier): the 5 latest open tasks

Write a SQL query that returns the id, title and created_at of the 5 newest tasks that are not done yet. Test it in the Database tab (SQL command), then keep it in your file.

เขียน SQL ที่คืน id, title และ created_at ของ task ใหม่ล่าสุด 5 รายการที่ยังไม่เสร็จ ทดลองใน tab Database (SQL command) แล้วเก็บไว้ในไฟล์ของคุณ

Edit db/queries.sql (in the Explorer: build › db › queries.sql). Write the query between the comments @tutorial:begin exercise-1-latest-open and @tutorial:end exercise-1-latest-open.

Hint

You need WHERE done = 0, ORDER BY created_at DESC and LIMIT 5, in this order.

Solution

In db/queries.sql, between the comments of exercise-1-latest-open:

SELECT id, title, created_at
FROM tasks
WHERE done = 0
ORDER BY created_at DESC
LIMIT 5;

Exercise 2 (harder): GET /api/stats

Add a route that answers { "total": 14, "done": 6 }: the number of tasks and how many of them are done (use the real numbers of the database). One SQL query is enough: look at COUNT(*) and SUM(done). The file is already connected to the app, so it answers 404 only until you write the route.

เพิ่ม route ที่ตอบ { "total": 14, "done": 6 }: จำนวน task ทั้งหมดและจำนวนที่เสร็จแล้ว (ใช้ตัวเลขจริงจากฐานข้อมูล) query เดียวก็พอ: ดู COUNT(*) และ SUM(done) ไฟล์นี้ต่อกับแอปไว้แล้ว จึงตอบ 404 จนกว่าคุณจะเขียน route

Edit server/routes/stats.js (in the Explorer: build › server › routes › stats.js). Write the route between the comments @tutorial:begin exercise-2-stats and @tutorial:end exercise-2-stats.

Hint

Copy the shape of the route from step 1.6. In the route use router.get('/', ...) (the path /api/stats is already added in app.js). Send one object with res.json(rows[0]). SUM of an empty table is NULL, so wrap it: COALESCE(SUM(done), 0).

Solution

In server/routes/stats.js, between the comments of exercise-2-stats:

router.get('/', async (req, res, next) => {
  try {
    const [rows] = await db.query(
      'SELECT COUNT(*) AS total, CAST(COALESCE(SUM(done), 0) AS UNSIGNED) AS done FROM tasks',
    );
    res.json(rows[0]);
  } catch (err) {
    next(err);
  }
});
  PASS  db/queries.sql has the query for the 5 latest open tasks
  PASS  GET /api/stats returns the totals of the database
