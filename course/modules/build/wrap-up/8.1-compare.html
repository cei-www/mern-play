Step 8.1: Compare with the reference

You built a complete app: a MySQL database, an Express API with seven kinds of route and a React page with six components of your own. Compare your code with the finished version when you want to see another way of writing the same thing.

The finished code is in the same files, but your zones now hold your code. To see the reference version, copy your work first (for example docker cp ce-webdev-academy-ws-main-1:/workspace/build ./my-build on your computer), then type:

คุณสร้างแอปที่สมบูรณ์: ฐานข้อมูล MySQL, Express API ที่มี route 7 แบบ และหน้า React ที่มี component ฝีมือคุณ 6 ตัว เมื่ออยากเห็นวิธีเขียนแบบอื่น ให้เทียบโค้ดของคุณกับฉบับสำเร็จ

โค้ดฉบับสำเร็จอยู่ในไฟล์เดียวกัน แต่ตอนนี้ zone ของคุณมีโค้ดของคุณ ถ้าอยากดูฉบับอ้างอิง ให้คัดลอกงานของคุณไว้ก่อน (เช่น docker cp ce-webdev-academy-ws-main-1:/workspace/build ./my-build บนเครื่องของคุณ) แล้วพิมพ์:

tutorial goto 0.1

This writes the finished version into every step zone. It keeps your exercise work. Look at differences: did you name things differently? Did the reference handle an edge case you did not?

Questions to think about: Where would you add a login? What happens with ten thousand tasks (paging)? Which routes need more tests?
