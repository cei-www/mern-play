Step 8.2: Where to go next

The other modules of this course use the same Task Manager:

  • Tailwind CSS: restyle the React page with utility classes.
  • Unit testing: write tests for the validation, the sort whitelist and the components.
  • API automation with Robot Framework: test the API from the outside, including checks in the database. It runs in its own container (start it with docker compose start ws-robot).

Each module starts from its own reference code, so you can take any of them without finishing this one.

module อื่นของคอร์สนี้ใช้ Task Manager ตัวเดียวกัน:

  • Tailwind CSS: ตกแต่งหน้า React ใหม่ด้วย utility class
  • Unit testing: เขียนเทสต์ให้ validation, whitelist ของการเรียงลำดับ และ component
  • API automation ด้วย Robot Framework: ทดสอบ API จากภายนอก รวมถึงตรวจในฐานข้อมูล ทำงานใน container แยก (เปิดด้วย docker compose start ws-robot)

แต่ละ module เริ่มจากโค้ดอ้างอิงของตัวเอง จึงเรียน module ไหนก่อนก็ได้โดยไม่ต้องเรียนอันนี้จบ
