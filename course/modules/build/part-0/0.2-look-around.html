Step 0.2: Look around your workspace

Open the Editor tab. In the Explorer on the left you will see the folder build. It has two projects: server (Express) and client (React).

The paths below are inside the build folder. Open the files. You can press Ctrl+P (Cmd+P on a Mac) and paste the path. Click a path to copy it.

เปิด tab Editor ที่ Explorer ด้านซ้ายจะเห็นโฟลเดอร์ build ซึ่งมี 2 โปรเจกต์คือ server (Express) กับ client (React)

path ด้านล่างอยู่ในโฟลเดอร์ build เปิดไฟล์เหล่านี้ ใช้ Ctrl+P (บน Mac คือ Cmd+P) แล้ววาง path ได้ คลิกที่ path เพื่อคัดลอก

  • server/app.js: the Express app and its routes
  • server/db.js: the connection to MySQL
  • server/.env: database settings
  • client/src/App.jsx: the React page

The API is already running. Open it in the Preview tab:

API กำลังทำงานอยู่แล้ว เปิดดูใน tab Preview:
