Step 0.1: What you will build

In this course you build a Task Manager: a small web app where you keep a list of tasks, put them into groups, sort them, and look back at the tasks you have finished.

It has three layers, and you will touch all of them:

  • MySQL stores the data (tasks, groups, users).
  • Express is the API. It reads and writes the database and answers over HTTP.
  • React is the page you see in the browser. It calls the API.

ในคอร์สนี้คุณจะสร้าง Task Manager เป็นเว็บแอปเล็ก ๆ สำหรับจดรายการงาน จัดงานเป็นกลุ่ม เรียงลำดับ และย้อนดูงานที่ทำเสร็จแล้ว

แอปมี 3 ชั้น และคุณจะได้ลงมือทำครบทุกชั้น:

  • MySQL เก็บข้อมูล (tasks, groups, users)
  • Express คือ API อ่านและเขียนฐานข้อมูล แล้วตอบกลับผ่าน HTTP
  • React คือหน้าเว็บที่คุณเห็นในเบราว์เซอร์ และเรียกใช้ API

The app is already finished in your workspace. First you will use it, then look at how it is built, then wipe the code of each feature and write it yourself, story by story.

On the right is a real editor (the Editor tab) with the project inside. Nothing to install. The same right pane also has Preview (your app), Database and Swagger.

แอปนี้ เสร็จสมบูรณ์แล้ว ใน workspace ของคุณ ขั้นแรกคุณจะลองใช้ ต่อมาดูว่าสร้างอย่างไร แล้วจึงลบโค้ดของแต่ละฟีเจอร์ออก และเขียนเองทีละ story

ฝั่งขวาคือ editor จริง (tab Editor) ที่มีโปรเจกต์อยู่ข้างใน ไม่ต้องติดตั้งอะไรเพิ่ม และมี tab Preview (แอปของคุณ), Database และ Swagger ในแถบเดียวกัน

You only need to mark a step as done when you want to remember where you stopped (button at the bottom). The progress is saved in this browser. Some steps end with a check: a command you type in the editor's terminal.

กดปุ่ม Mark as done ที่ท้ายหน้า เมื่ออยากจำว่าเรียนถึงไหนแล้ว ความคืบหน้าถูกเก็บไว้ในเบราว์เซอร์นี้ บาง step ปิดท้ายด้วยการตรวจ ซึ่งเป็นคำสั่งที่พิมพ์ใน terminal ของ editor
