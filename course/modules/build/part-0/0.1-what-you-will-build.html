Step 0.1: What you will build

In this course you build a Task Manager: a small web app where you keep a list of tasks, put them into groups, sort them, and look back at the tasks you have finished.

It has three layers, and you will touch all of them:

  • MySQL stores the data (tasks, groups, users).
  • Express is the API. It reads and writes the database and answers over HTTP.
  • React is the page you see in the browser. It calls the API.

ในคอร์สนี้คุณจะสร้าง Task Manager เป็นเว็บแอปเล็ก ๆ สำหรับจดรายการงาน จัดงานเป็นกลุ่ม เรียงลำดับ และย้อนดูงานที่ทำเสร็จแล้ว

แอปมี 3 ชั้น และคุณจะได้ลงมือทำครบทุกชั้น:

  • MySQL เก็บข้อมูล (tasks, groups, users)
  • Express คือ API อ่านและเขียนฐานข้อมูล แล้วตอบกลับผ่าน HTTP
  • React คือหน้าเว็บที่คุณเห็นในเบราว์เซอร์ และเรียกใช้ API

On the right you have a real editor (the Editor tab) with the project already inside. Nothing to install.
