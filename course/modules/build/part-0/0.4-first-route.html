Step 0.4: Add your first route

A route connects a URL to some code. You will add one that answers /api/hello.

Route คือสิ่งที่เชื่อม URL เข้ากับโค้ด คุณจะเพิ่ม route ที่ตอบ /api/hello

Edit server/app.js. Put the new code on the line right after app.use(express.json());.

app.get('/api/hello', (req, res) => {
  res.json({ hello: 'world' });
});

Save the file (Ctrl+S). The server restarts by itself. Then open the route:

บันทึกไฟล์ (Ctrl+S) เซิร์ฟเวอร์จะรีสตาร์ตเอง จากนั้นเปิด route ที่เพิ่ม:

Open /api/hello

Hint

Do not delete the lines that are already there. The new route goes between app.use(express.json()); and the next route.

  PASS  GET /api/hello returned 200 with { "hello": "world" }
