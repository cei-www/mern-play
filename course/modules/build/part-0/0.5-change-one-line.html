Step 0.5: Change one line

Time for your first edit. The heading of the page comes from one line of the React code. Change its text and watch the page update without reloading (Vite calls this hot module replacement).

ถึงเวลาแก้โค้ดครั้งแรก หัวข้อของหน้าเว็บมาจากโค้ด React บรรทัดเดียว ลองเปลี่ยนข้อความแล้วดูหน้าเว็บอัปเดต โดยไม่ต้อง reload (Vite เรียกว่า hot module replacement)

Edit client/src/App.jsx (in the Explorer: build › client › src › App.jsx). Find the line that starts with const APP_TITLE = (near the top, below the imports) and change the text between the quotes.

const APP_TITLE = 'My Task Manager';

Save the file (Ctrl+S) and look at the Preview tab. Use any title you like.

บันทึกไฟล์ (Ctrl+S) แล้วดูที่ tab Preview จะตั้งชื่ออะไรก็ได้

Open the app in Preview

Hint

The line is const APP_TITLE = 'Task Manager';. Keep the quotes and the semicolon.
