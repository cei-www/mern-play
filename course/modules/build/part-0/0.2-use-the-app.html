Step 0.2: Use the finished app

Open the Preview tab. It shows your Task Manager. Try it like a user:

  1. Add a task with the title My first task (priority and date are up to you).
  2. Tick the checkbox of a task to complete it.
  3. Pick a group (Work, Home or Study) and change Show and Sort by.
  4. Open the History tab: your completed tasks are listed, newest first.

เปิด tab Preview จะเห็น Task Manager ของคุณ ลองใช้เหมือนผู้ใช้จริง:

  1. เพิ่ม task ชื่อ My first task (priority และวันที่เลือกได้ตามสบาย)
  2. ติ๊ก checkbox ของ task เพื่อทำให้เสร็จ
  3. เลือก group (Work, Home หรือ Study) และลองเปลี่ยน Show กับ Sort by
  4. เปิด tab History จะเห็น task ที่ทำเสร็จแล้ว เรียงจากใหม่ไปเก่า

Open the app in Preview

Every click you made became a request to the API, and the API changed the database. Open the Database tab, press Login, and open the table tasks (Select data): your task is there.

ทุกการคลิกของคุณกลายเป็น request ไปที่ API และ API ก็แก้ฐานข้อมูล เปิด tab Database กด Login แล้วเปิดตาราง tasks (Select data) จะเห็น task ของคุณอยู่ในนั้น

Hint

If the Preview tab shows an error, wait a few seconds and try again. The servers restart by themselves when a file changes.
