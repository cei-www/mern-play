Step 0.3: Try the API in Swagger

Swagger is a page that lists every endpoint of the Task Manager API and lets you call it with a button, without writing any code.

Open the Swagger tab, pick GET /api/health, press Try it out, then Execute. You should get 200 and {"status":"ok"}.

Swagger คือหน้าที่แสดง endpoint ทั้งหมดของ Task Manager API และให้คุณเรียกใช้ด้วยการกดปุ่ม โดยไม่ต้องเขียนโค้ด

เปิด tab Swagger เลือก GET /api/health กด Try it out แล้วกด Execute จะได้ 200 และ {"status":"ok"}

Now try GET /api/tasks. It answers 404. That is expected: you have not built that endpoint yet. Swagger describes the finished API, so a 404 here is your to-do list.

ลอง GET /api/tasks จะได้ 404 ซึ่งถูกต้องแล้ว เพราะคุณยังไม่ได้สร้าง endpoint นี้ Swagger แสดง API ฉบับสมบูรณ์ ดังนั้น 404 ตรงนี้คือสิ่งที่ต้องทำต่อ
