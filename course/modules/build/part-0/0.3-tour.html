Step 0.3: A tour of the project

Open the Editor tab. In the Explorer on the left you see the folder build with two projects: server (Express) and client (React). The paths below are inside build. Open the files by browsing the folders in the Explorer.

เปิด tab Editor ที่ Explorer ด้านซ้ายจะเห็นโฟลเดอร์ build ที่มี 2 โปรเจกต์คือ server (Express) กับ client (React) path ด้านล่างอยู่ในโฟลเดอร์ build เปิดไฟล์โดยเลือกดูตามโฟลเดอร์ใน Explorer ด้วยตัวเอง

  • server/app.js: starts Express and connects the routes
  • server/routes/tasks.js: the routes for /api/tasks, with the SQL
  • server/db.js: the connection to MySQL
  • client/src/App.jsx: the React page that puts the parts together
  • client/src/components/TaskList.jsx: the list of tasks

Notice the comments that contain @tutorial:begin and @tutorial:end in some files. They mark the code you will write later. Do not delete those comment lines.

Now watch the traffic. Open your app in Preview, open the browser's developer tools (F12), go to the Network tab and reload the page. Find the request named tasks: it is the call from React to the Express API, and its Response is the JSON that React shows.

สังเกตคอมเมนต์ที่มีคำว่า @tutorial:begin และ @tutorial:end ในบางไฟล์ คอมเมนต์เหล่านี้ทำเครื่องหมายโค้ดที่คุณจะเขียนเองภายหลัง ห้ามลบบรรทัดคอมเมนต์เหล่านี้

ลองดู traffic เปิดแอปใน Preview เปิด developer tools ของเบราว์เซอร์ (F12) ไปที่ tab Network แล้ว reload หน้า หา request ชื่อ tasks นั่นคือการที่ React เรียก Express API และ Response คือ JSON ที่ React นำมาแสดง
