Step 7.4: DELETE /api/tasks/:id

DELETE removes a task and answers 204 with no body. Here result.affectedRows tells you whether a row was deleted: 0 means there was no such task, so the answer is 404. Deleting the same task twice therefore gives 204 and then 404.

DELETE ลบ task และตอบ 204 โดยไม่มี body ตรงนี้ result.affectedRows บอกว่ามีแถวถูกลบหรือไม่: 0 หมายถึงไม่มี task นั้น จึงตอบ 404 การลบ task เดียวกันสองครั้งจึงได้ 204 แล้วตามด้วย 404

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s7-4-delete-task and @tutorial:end s7-4-delete-task.

router.delete('/:id', async (req, res, next) => {
  const id = Number(req.params.id);
  if (!Number.isInteger(id)) return res.status(400).json({ error: 'id must be a whole number' });
  try {
    const [result] = await db.query('DELETE FROM tasks WHERE id = ?', [id]);
    if (result.affectedRows === 0) return res.status(404).json({ error: 'Task not found' });
    res.status(204).end();
  } catch (err) {
    next(err);
  }
});

Create a task in Swagger first (createTask), note its id, delete it, then delete it again.

สร้าง task ใน Swagger ก่อน (createTask) จด id ลบมัน แล้วลบอีกครั้ง

Hint

res.status(204).end() sends the answer with no body. Do not use res.json for 204.
