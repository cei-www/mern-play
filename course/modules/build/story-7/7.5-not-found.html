Step 7.5: One error shape

When a client asks for a path that does not exist under /api, Express answers with an HTML page. Add a catch-all that answers the JSON error shape instead.

Express runs app.use in order, so this one sits after all the real routes: it only runs when no route answered. The error handler at the very end of app.js (already there) catches everything that was passed to next(err) and answers 500 with the same shape.

เมื่อ client ขอ path ที่ไม่มีอยู่ใต้ /api Express จะตอบเป็นหน้า HTML เพิ่มตัวรับทั้งหมดที่ตอบเป็น JSON รูปแบบ error แทน

Express รัน app.use ตามลำดับ ตัวนี้จึงอยู่ หลัง route จริงทั้งหมด: มันทำงานเฉพาะเมื่อไม่มี route ไหนตอบ ตัวจัดการ error ท้ายสุดของ app.js (มีอยู่แล้ว) รับทุกอย่างที่ส่งด้วย next(err) และตอบ 500 ด้วยรูปแบบเดียวกัน

Edit server/app.js (in the Explorer: build › server › app.js). Write the code between the comments @tutorial:begin s7-5-not-found and @tutorial:end s7-5-not-found.

app.use('/api', (req, res) => {
  res.status(404).json({ error: 'Not found' });
});
