Step 7.2: GET /api/tasks/:id

Read one task by its id. :id in the path is a route parameter; it arrives as text in req.params.id, so convert it with Number() and check it.

Three answers: 400 for an id that is not a number, 404 when no row has that id, 200 with the task otherwise. The helper findTask(id) at the top of the file reads one task with its group name.

อ่าน task หนึ่งชิ้นด้วย id :id ใน path คือ route parameter มาถึงเป็นข้อความใน req.params.id จึงต้องแปลงด้วย Number() และตรวจ

คำตอบมี 3 แบบ: 400 เมื่อ id ไม่ใช่ตัวเลข 404 เมื่อไม่มีแถวที่มี id นั้น และ 200 พร้อม task ในกรณีอื่น ตัวช่วย findTask(id) ที่ต้นไฟล์อ่าน task หนึ่งชิ้นพร้อมชื่อ group

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s7-2-get-one and @tutorial:end s7-2-get-one.

router.get('/:id', async (req, res, next) => {
  const id = Number(req.params.id);
  if (!Number.isInteger(id)) return res.status(400).json({ error: 'id must be a whole number' });
  try {
    const task = await findTask(id);
    if (!task) return res.status(404).json({ error: 'Task not found' });
    res.json(task);
  } catch (err) {
    next(err);
  }
});

Hint

Order: check the id with Number.isInteger, call await findTask(id), answer 404 when it returns nothing.
