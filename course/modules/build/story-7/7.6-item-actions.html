Step 7.6: Edit and delete in the page

Two buttons in each row. Edit asks for a new title (window.prompt), sends PUT with the other fields as they are, and shows the server's message if it refuses. Delete asks to confirm (window.confirm) and sends DELETE. Both then call onChanged() to reload.

The pop-up boxes keep the lesson short. A real product would use a dialog in the page.

ปุ่ม 2 ปุ่มในแต่ละแถว Edit ถามชื่อใหม่ (window.prompt) ส่ง PUT พร้อมฟิลด์อื่นตามเดิม และแสดงข้อความจาก server ถ้าถูกปฏิเสธ Delete ขอให้ยืนยัน (window.confirm) แล้วส่ง DELETE ทั้งสองปุ่มเรียก onChanged() เพื่อโหลดใหม่

กล่องป๊อปอัปทำให้บทเรียนสั้น ผลิตภัณฑ์จริงจะใช้ dialog ในหน้าเว็บ

Edit client/src/components/TaskItem.jsx (in the Explorer: build › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s7-6-item-actions and @tutorial:end s7-6-item-actions (inside JSX, so they look like {/* ... */}).

<button
  type="button"
  onClick={async () => {
    const title = window.prompt('New title', task.title);
    if (!title) return;
    const res = await fetch(`/api/tasks/${task.id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ title, priority: task.priority, due_date: task.due_date, group_id: task.group_id }),
    });
    if (!res.ok) window.alert((await res.json()).error);
    onChanged?.();
  }}
>
  Edit
</button>
<button
  type="button"
  onClick={async () => {
    if (!window.confirm(`Delete "${task.title}"?`)) return;
    await fetch(`/api/tasks/${task.id}`, { method: 'DELETE' });
    onChanged?.();
  }}
>
  Delete
</button>
