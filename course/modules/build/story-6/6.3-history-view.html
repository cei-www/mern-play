Step 6.3: The History tab

The page already has the two tabs Tasks and History (written for you in App.jsx). The History tab shows HistoryView: a select for the number of days and the finished tasks with the time they were completed.

Notice useEffect with [days, groupId, reloadKey]: it loads again when the learner changes the days, picks another group, or something else changed a task.

หน้าเว็บมี 2 tab Tasks และ History อยู่แล้ว (เขียนไว้ให้ใน App.jsx) tab History แสดง HistoryView: select จำนวนวัน และรายการ task ที่เสร็จแล้วพร้อมเวลาที่ทำเสร็จ

สังเกต useEffect ที่มี [days, groupId, reloadKey]: มันโหลดใหม่เมื่อผู้ใช้เปลี่ยนจำนวนวัน เลือก group อื่น หรือมีสิ่งอื่นเปลี่ยน task

Edit client/src/components/HistoryView.jsx (in the Explorer: build › client › src › components › HistoryView.jsx). Write the code between the comments @tutorial:begin s6-3-history-view and @tutorial:end s6-3-history-view, inside the function.

const [days, setDays] = useState(7);
const [tasks, setTasks] = useState([]);
const [error, setError] = useState('');

useEffect(() => {
  fetch(`/api/tasks/history${toQuery({ days, group_id: groupId })}`)
    .then((res) => {
      if (!res.ok) throw new Error(`The server answered ${res.status}`);
      return res.json();
    })
    .then((data) => {
      setTasks(data);
      setError('');
    })
    .catch((err) => setError(err.message));
}, [days, groupId, reloadKey]);

return (
  <section>
    <label>
      Completed in the last
      <select value={days} onChange={(e) => setDays(Number(e.target.value))}>
        <option value={1}>1 day</option>
        <option value={7}>7 days</option>
        <option value={30}>30 days</option>
      </select>
    </label>
    {error && <p role="alert">{error}</p>}
    {tasks.length === 0 && !error && <p>Nothing completed in this period.</p>}
    <ul className="task-list">
      {tasks.map((task) => (
        <li key={task.id} className="task task-done">
          <span className="task-title">{task.title}</span>
          {task.group_name && <span className="badge">{task.group_name}</span>}
          <span className="due">done {task.completed_at}</span>
        </li>
      ))}
    </ul>
  </section>
);
