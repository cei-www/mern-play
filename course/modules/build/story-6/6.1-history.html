Step 6.1: History is a query

As a user, I want to look back at the tasks I finished, so that I can see what I achieved.

History does not need a new table. A finished task already has done = 1 and a time in completed_at (Story 3). History is a query on the same table: the done tasks of the last N days, newest first.

As a user, I want to look back at the tasks I finished, so that I can see what I achieved.

history ไม่ต้องมีตารางใหม่ task ที่เสร็จแล้วมี done = 1 และเวลาใน completed_at อยู่แล้ว (Story 3) history คือ query บนตารางเดิม: task ที่เสร็จใน N วันล่าสุด เรียงจากใหม่ไปเก่า

SELECT t.*, g.name AS group_name
FROM tasks t
LEFT JOIN task_groups g ON g.id = t.group_id
WHERE t.done = 1 AND t.completed_at >= NOW() - INTERVAL 7 DAY
ORDER BY t.completed_at DESC;

Run it in the Database tab, then change 7 to 1 and compare. The sample data has tasks finished one hour ago, one day ago and several days ago.

รันใน tab Database แล้วเปลี่ยน 7 เป็น 1 และเปรียบเทียบ ข้อมูลตัวอย่างมี task ที่เสร็จเมื่อ 1 ชั่วโมงก่อน 1 วันก่อน และหลายวันก่อน
