Step 6.2: GET /api/tasks/history

The route reads days (default 7, a whole number of at least 1) and an optional group_id. Placeholders hold both values, including the number of days.

Order matters. The route GET /:id would take the word history as an id. The history route is therefore written before any /:id route, and the zone for it is already in the right place in the file.

route อ่าน days (ค่าเริ่มต้น 7 เป็นจำนวนเต็มตั้งแต่ 1) และ group_id ที่ใส่หรือไม่ก็ได้ ค่าทั้งสองใส่ด้วย placeholder รวมถึงจำนวนวัน

ลำดับสำคัญ route GET /:id จะอ่านคำว่า history เป็น id ดังนั้น route history ต้องเขียน ก่อน route /:id ใด ๆ และ zone ของมันอยู่ในตำแหน่งที่ถูกต้องในไฟล์แล้ว

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s6-2-history and @tutorial:end s6-2-history.

// Must stay above GET /:id, otherwise "history" would be read as an id.
router.get('/history', async (req, res, next) => {
  const days = req.query.days === undefined ? 7 : Number(req.query.days);
  if (!Number.isInteger(days) || days < 1) return res.status(400).json({ error: 'days must be a whole number of at least 1' });
  const params = [days];
  let groupFilter = '';
  if (req.query.group_id !== undefined) {
    if (!/^\d+$/.test(req.query.group_id)) return res.status(400).json({ error: 'group_id must be a whole number' });
    groupFilter = 'AND t.group_id = ?';
    params.push(Number(req.query.group_id));
  }
  try {
    const [rows] = await db.query(
      `${SELECT_TASKS} WHERE t.done = 1 AND t.completed_at >= NOW() - INTERVAL ? DAY ${groupFilter} ORDER BY t.completed_at DESC`,
      params,
    );
    res.json(rows);
  } catch (err) {
    next(err);
  }
});

Save and try taskHistory in Swagger with days 1, 7 and 0 (that one answers 400).

บันทึกแล้วลอง taskHistory ใน Swagger ด้วย days เป็น 1, 7 และ 0 (ค่าสุดท้ายตอบ 400)

Hint

NOW() - INTERVAL ? DAY works with a placeholder. Build the optional part of the SQL as a text that is either empty or 'AND t.group_id = ?', and add the value to the array only in the second case.

Solution

In server/routes/tasks.js, between the comments of s6-2-history:
