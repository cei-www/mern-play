Step 5.3: Why ORDER BY needs a whitelist

A ? placeholder always stands for a value and MySQL puts it in quotes. If you wrote ORDER BY ? and gave it title, MySQL would sort by the text "title" for every row, which is no sorting at all. A column name is part of the SQL structure, and only the SQL text can hold it.

So the code puts the name into the text. If it came from the request, an attacker could send sort=title; DROP TABLE tasks. The whitelist cuts this off: the request chooses only a key; the SQL text always comes from your own object.

placeholder ? แทน ค่า เสมอ และ MySQL ใส่เครื่องหมายคำพูดให้ ถ้าคุณเขียน ORDER BY ? แล้วส่ง title MySQL จะเรียงตาม ข้อความ "title" ซึ่งเท่ากันทุกแถว จึงไม่ได้เรียงอะไรเลย ชื่อคอลัมน์เป็นส่วนของ โครงสร้าง SQL และอยู่ได้เฉพาะในข้อความ SQL

โค้ดจึงใส่ชื่อลงในข้อความ ถ้าชื่อมาจาก request ผู้โจมตีอาจส่ง sort=title; DROP TABLE tasks whitelist ตัดปัญหานี้: request เลือกได้แค่ key ส่วนข้อความ SQL มาจาก object ของคุณเสมอ

Try it on your own API. This must answer 400, not 200 and not 500:

ลองกับ API ของคุณ ต้องได้ 400 ไม่ใช่ 200 และไม่ใช่ 500:

Open /api/tasks?sort=title;drop
