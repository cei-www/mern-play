Step 5.4: Filter and sort controls

SortBar has three selects: Show (all, open or done), Sort by and Order. value is an object { done, sort, order } and onChange receives a new object. The page builds the query string from it (with toQuery in api.js) and passes it to TaskList.

The helper set(key) makes one change handler per select: it copies the object and replaces one key.

SortBar มี select 3 ตัว: Show (all, open หรือ done), Sort by และ Order value คือ object { done, sort, order } และ onChange รับ object ใหม่ หน้าเว็บสร้าง query string จากมัน (ด้วย toQuery ใน api.js) แล้วส่งให้ TaskList

ตัวช่วย set(key) สร้าง handler ให้ select แต่ละตัว: คัดลอก object แล้วแทนที่หนึ่ง key

Edit client/src/components/SortBar.jsx (in the Explorer: build › client › src › components › SortBar.jsx). Write the code between the comments @tutorial:begin s5-4-sort-bar and @tutorial:end s5-4-sort-bar, inside the function.

const set = (key) => (event) => onChange({ ...value, [key]: event.target.value });

return (
  <div className="sort-bar">
    <label>
      Show
      <select value={value.done} onChange={set('done')}>
        <option value="">all</option>
        <option value="0">open</option>
        <option value="1">done</option>
      </select>
    </label>
    <label>
      Sort by
      <select value={value.sort} onChange={set('sort')}>
        <option value="">newest</option>
        <option value="due_date">due date</option>
        <option value="priority">priority</option>
        <option value="title">title</option>
      </select>
    </label>
    <label>
      Order
      <select value={value.order} onChange={set('order')}>
        <option value="asc">ascending</option>
        <option value="desc">descending</option>
      </select>
    </label>
  </div>
);

Save and use the controls in Preview. Then select a group in the group buttons: now the list is filtered too, because the page sends group_id and your route from step 5.2 understands it.

บันทึกแล้วลองใช้ตัวควบคุมใน Preview จากนั้นเลือก group ที่ปุ่ม group: ตอนนี้รายการถูกกรองด้วย เพราะหน้าเว็บส่ง group_id และ route จาก step 5.2 เข้าใจมัน

Hint

Each <select> needs value={value.sort} and onChange={set('sort')}. An option with value="" means "not chosen", which toQuery leaves out.
