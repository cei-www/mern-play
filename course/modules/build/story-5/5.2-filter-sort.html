Step 5.2: Filter and sort GET /api/tasks

You will add a second route for GET / above the plain one from Story 1. Express tries routes in order:

  • If the request has none of the four options, the new route calls next() and the plain route answers, as before.
  • If it has options, the new route checks them, builds the SQL and answers.

Two safety rules matter here:

  • Values (done, group_id) go into the query as ? placeholders, like before.
  • The column name for sorting cannot be a placeholder (see the next step). It comes from a whitelist: the object SORT_COLUMNS maps the allowed words to real column names, and any other word is refused with 400.

คุณจะเพิ่ม route ที่สองสำหรับ GET / ไว้เหนือ route ธรรมดาจาก Story 1 Express ลองทีละ route ตามลำดับ:

  • ถ้า request ไม่มีตัวเลือกทั้งสี่ route ใหม่จะเรียก next() แล้ว route ธรรมดาตอบเหมือนเดิม
  • ถ้ามีตัวเลือก route ใหม่จะตรวจ สร้าง SQL และตอบ

กฎความปลอดภัย 2 ข้อที่สำคัญตรงนี้:

  • ค่า (done, group_id) ใส่ใน query ด้วย placeholder ? เหมือนเดิม
  • ชื่อคอลัมน์ สำหรับเรียงลำดับใช้ placeholder ไม่ได้ (ดู step ถัดไป) จึงมาจาก whitelist: object SORT_COLUMNS แปลงคำที่อนุญาตเป็นชื่อคอลัมน์จริง และคำอื่นถูกปฏิเสธด้วย 400

Edit server/routes/tasks.js (in the Explorer: build › server › routes › tasks.js). Write the code between the comments @tutorial:begin s5-2-filter-sort and @tutorial:end s5-2-filter-sort.

// Only these columns may be used for sorting. The value goes into the SQL text,
// so it must never come straight from the request.
const SORT_COLUMNS = { created_at: 't.created_at', due_date: 't.due_date', priority: 't.priority', title: 't.title' };

// Handles GET /api/tasks when the request has filter or sort options.
// Without options it calls next() and the plain route below answers.
router.get('/', async (req, res, next) => {
  const { done, group_id: groupId, sort, order = 'asc' } = req.query;
  if (done === undefined && groupId === undefined && sort === undefined && req.query.order === undefined) return next();

  const where = [];
  const params = [];
  if (done !== undefined) {
    if (done !== '0' && done !== '1') return res.status(400).json({ error: 'done must be 0 or 1' });
    where.push('t.done = ?');
    params.push(Number(done));
  }
  if (groupId !== undefined) {
    if (!/^\d+$/.test(groupId)) return res.status(400).json({ error: 'group_id must be a whole number' });
    where.push('t.group_id = ?');
    params.push(Number(groupId));
  }
  if (sort !== undefined && !(sort in SORT_COLUMNS)) {
    return res.status(400).json({ error: `sort must be one of: ${Object.keys(SORT_COLUMNS).join(', ')}` });
  }
  if (order !== 'asc' && order !== 'desc') return res.status(400).json({ error: 'order must be asc or desc' });

  const column = SORT_COLUMNS[sort ?? 'created_at'];
  // Tasks without a due date go last when sorting by due date.
  const nullsLast = column === 't.due_date' ? 't.due_date IS NULL, ' : '';
  const sql = `${SELECT_TASKS} ${where.length ? `WHERE ${where.join(' AND ')}` : ''} ORDER BY ${nullsLast}${column} ${order}, t.id`;
  try {
    const [rows] = await db.query(sql, params);
    res.json(rows);
  } catch (err) {
    next(err);
  }
});

Hint

Start with the if that calls next() when nothing is set. Then build two arrays: where (pieces such as 't.done = ?') and params (their values). Join the pieces with AND. For the sort column use SORT_COLUMNS[sort ?? 'created_at'].
