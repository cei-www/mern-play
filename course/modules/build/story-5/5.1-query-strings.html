Step 5.1: Query strings

As a user, I want to show only some tasks and sort them, so that I can focus on what matters now.

A query string is the part of a URL after ?. It holds options as name=value pairs joined by &:

As a user, I want to show only some tasks and sort them, so that I can focus on what matters now.

query string คือส่วนของ URL ที่อยู่หลัง ? ใช้ส่งตัวเลือกเป็นคู่ name=value เชื่อมกันด้วย &:

/api/tasks?done=0&group_id=1&sort=priority&order=desc

In Express they arrive in req.query as text: { done: '0', group_id: '1', sort: 'priority', order: 'desc' }. Your route must check every value, because anyone can type anything in a URL.

The API accepts done (0 or 1), group_id (a number), sort (one of four columns) and order (asc or desc). Open the Swagger operation listTasks: Swagger shows these options as a form.

ใน Express ค่าเหล่านี้มาอยู่ใน req.query เป็น ข้อความ: { done: '0', group_id: '1', sort: 'priority', order: 'desc' } route ของคุณต้องตรวจทุกค่า เพราะใครก็พิมพ์อะไรใน URL ก็ได้

API รับ done (0 หรือ 1), group_id (ตัวเลข), sort (หนึ่งในสี่คอลัมน์) และ order (asc หรือ desc) เปิด operation listTasks ใน Swagger: Swagger แสดงตัวเลือกเหล่านี้เป็นฟอร์ม
