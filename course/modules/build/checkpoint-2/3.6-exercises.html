Exercise 3 (easier): Summary

Write the component Summary. It receives the list tasks as a prop and shows how many are done, in this form: 2 of 14 done. (A task is done when task.done === 1.) The page already shows it above the form.

เขียน component Summary รับรายการ tasks เป็น prop และแสดงจำนวนที่เสร็จแล้วในรูปแบบ 2 of 14 done (task เสร็จเมื่อ task.done === 1) หน้าเว็บแสดงมันไว้เหนือฟอร์มอยู่แล้ว

Edit client/src/components/Summary.jsx (in the Explorer: build › client › src › components › Summary.jsx). Write the code between the comments @tutorial:begin exercise-3-summary and @tutorial:end exercise-3-summary, inside the function.

Hint

Count with tasks.filter((task) => task.done === 1).length and return a <p>.

Solution

In client/src/components/Summary.jsx, between the comments of exercise-3-summary:

const done = tasks.filter((task) => task.done === 1).length;
return (
  <p className="summary">
    {done} of {tasks.length} done
  </p>
);

Exercise 4 (harder): GET /api/search

Write GET /api/search?q=milk. It answers the tasks whose title contains the text q (use LIKE with % signs around the value, and a placeholder). Newest first, with group_name like the list. When q is missing or empty, answer 400 with { "error": "q is required" }.

เขียน GET /api/search?q=milk ให้ตอบ task ที่ title มี ข้อความ q อยู่ (ใช้ LIKE โดยใส่ % รอบค่า และใช้ placeholder) ใหม่สุดก่อน พร้อม group_name เหมือนรายการ เมื่อไม่มี q หรือว่าง ให้ตอบ 400 พร้อม { "error": "q is required" }

Edit server/routes/search.js (in the Explorer: build › server › routes › search.js). Write the code between the comments @tutorial:begin exercise-4-search and @tutorial:end exercise-4-search.

Hint

The % signs belong to the value, not to the SQL text: [`%${q}%`]. The file is already connected to the app at /api/search.

Solution

In server/routes/search.js, between the comments of exercise-4-search:

router.get('/', async (req, res, next) => {
  const q = typeof req.query.q === 'string' ? req.query.q.trim() : '';
  if (!q) return res.status(400).json({ error: 'q is required' });
  try {
    const [rows] = await db.query(
      `SELECT t.*, g.name AS group_name
       FROM tasks t
       LEFT JOIN task_groups g ON g.id = t.group_id
       WHERE t.title LIKE ?
       ORDER BY t.created_at DESC, t.id DESC`,
      [`%${q}%`],
    );
    res.json(rows);
  } catch (err) {
    next(err);
  }
});
