Step B.1: Test validation: valid, invalid and boundaries

validateTask(body) in src/server/validateTask.js checks the body of a request. It returns { value } when the task is fine and { error } when it is not. Rules: the title is 1 to 100 characters after trimming; the priority is 1, 2 or 3 (2 when missing).

A good set of tests for a rule like this has three kinds of cases:

  • valid: what is accepted and what it returns;
  • invalid: each way to be wrong;
  • boundaries: the values right at the edge. Bugs live at edges: a > that should have been >=. Here 100 characters are fine and 101 are not.

When many cases differ only in their data, write the test once and give it a table with it.each. Each row becomes its own test, and %s in the name is replaced by the first value of the row.

validateTask(body) ใน src/server/validateTask.js ตรวจ body ของ request คืน { value } เมื่อ task ถูกต้อง และ { error } เมื่อไม่ถูก กฎคือ: title ยาว 1 ถึง 100 ตัวอักษรหลังตัดช่องว่างหัวท้าย priority เป็น 1, 2 หรือ 3 (เป็น 2 เมื่อไม่ส่งมา)

ชุด test ที่ดีสำหรับกฎแบบนี้มีสามประเภท:

  • valid: อะไรที่รับ และคืนอะไร
  • invalid: ทุกวิธีที่ผิดได้
  • boundary: ค่าที่อยู่ตรงขอบ บั๊กชอบอยู่ที่ขอบ: > ที่ควรเป็น >= ตรงนี้ 100 ตัวอักษรได้ และ 101 ไม่ได้

เมื่อหลายกรณีต่างกันแค่ข้อมูล ให้เขียน test ครั้งเดียวแล้วให้ตารางด้วย it.each แต่ละแถวกลายเป็น test ของตัวเอง และ %s ในชื่อถูกแทนด้วยค่าแรกของแถว

Create the file tests/validateTask.test.js (in the Explorer: unit › tests › validateTask.test.js; right-click the folder, then New File). Paste the code into it and save.

import { describe, expect, it } from 'vitest';
import { validateTask } from '../src/server/validateTask.js';

describe('validateTask', () => {
  it('accepts a title and gives it priority 2 when none is sent', () => {
    expect(validateTask({ title: 'Buy milk' })).toEqual({ value: { title: 'Buy milk', priority: 2 } });
  });

  it('removes spaces around the title', () => {
    expect(validateTask({ title: '  Buy milk  ' }).value.title).toBe('Buy milk');
  });

  it.each([
    ['an empty title', { title: '' }],
    ['a title of only spaces', { title: '   ' }],
    ['no title at all', {}],
    ['a title that is not text', { title: 42 }],
  ])('rejects %s', (_name, body) => {
    expect(validateTask(body).error).toMatch(/title is required/);
  });

  it('accepts a title of exactly 100 characters', () => {
    expect(validateTask({ title: 'a'.repeat(100) }).error).toBeUndefined();
  });

  it('rejects a title of 101 characters', () => {
    expect(validateTask({ title: 'a'.repeat(101) }).error).toMatch(/1-100/);
  });

  it.each([0, 4, '3', null])('rejects the priority %s', (priority) => {
    expect(validateTask({ title: 'Buy milk', priority }).error).toBe('priority must be 1, 2 or 3');
  });
});
