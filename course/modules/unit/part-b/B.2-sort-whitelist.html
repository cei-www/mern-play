Step B.2: The sort whitelist rejects unsafe values

Remember why buildOrderBy has a list of allowed columns: the sort value ends up inside the SQL text, so a request like ?sort=title;DROP TABLE tasks must never get through. This is a security rule, and a rule like this needs tests that try to break it.

Add tests that send things that are not allowed and expect an error. toThrow(...) needs the code wrapped in a function, so that Vitest can call it and catch the error: expect(() => buildOrderBy('x')).toThrow('text'). The names constructor, toString and __proto__ exist on every JavaScript object, so a careless "is it in the list" check lets them in. Try them.

จำได้ไหมว่าทำไม buildOrderBy มีรายการคอลัมน์ที่อนุญาต: ค่า sort ไปอยู่ ในข้อความ SQL request อย่าง ?sort=title;DROP TABLE tasks จึงต้องผ่านไปไม่ได้ นี่คือกฎด้านความปลอดภัย และกฎแบบนี้ต้องมี test ที่พยายาม ทำลาย มัน

เพิ่ม test ที่ส่งสิ่งที่ไม่อนุญาตและคาดว่าจะเกิด error toThrow(...) ต้องห่อโค้ดไว้ในฟังก์ชัน เพื่อให้ Vitest เรียกและจับ error เอง: expect(() => buildOrderBy('x')).toThrow('text') ชื่อ constructor, toString และ __proto__ มีอยู่ในทุก object ของ JavaScript การเช็ก "อยู่ในรายการไหม" แบบลวก ๆ จึงปล่อยมันผ่าน ลองดู

Edit tests/orderBy.test.js (in the Explorer: unit › tests › orderBy.test.js). Add the code at the end of the file.

describe('buildOrderBy safety', () => {
  it('rejects a column that is not on the list', () => {
    expect(() => buildOrderBy('password')).toThrow('sort must be one of');
  });

  it('rejects SQL that is put into sort', () => {
    expect(() => buildOrderBy('title; DROP TABLE tasks')).toThrow();
    expect(() => buildOrderBy('1 OR 1=1')).toThrow();
  });

  it.each(['constructor', 'toString', '__proto__'])('rejects the object property name "%s"', (name) => {
    expect(() => buildOrderBy(name)).toThrow('sort must be one of');
  });

  it('rejects an order that is not asc or desc', () => {
    expect(() => buildOrderBy('title', 'sideways')).toThrow('order must be asc or desc');
  });
});
Hint

The error messages are in src/server/orderBy.js. toThrow('text') passes when the message contains that text.
