Step B.4: Mock db.query to test a service

createTask(input) in src/server/taskService.js validates the input, then runs an INSERT through db.query, and returns the new task. Test it without a database. Look at the three moves in the code:

  1. vi.mock(...) replaces db.js. Vitest moves it to the top of the file by itself, before the imports.
  2. mockResolvedValue([{ insertId: 42 }]) is the stub: MySQL answers with an array and the first item has the new id.
  3. The spy checks that the SQL has INSERT INTO tasks and that the values go in separately as parameters (never glued into the text) and in the right order.

beforeEach runs before every test; vi.clearAllMocks() forgets the calls of the last test, so tests do not affect each other.

createTask(input) ใน src/server/taskService.js ตรวจข้อมูล แล้วรัน INSERT ผ่าน db.query และคืน task ใหม่ ทดสอบมันโดยไม่ใช้ฐานข้อมูล ดูสามการเคลื่อนไหวในโค้ด:

  1. vi.mock(...) แทน db.js Vitest ย้ายมันไปไว้บนสุดของไฟล์เอง ก่อน import
  2. mockResolvedValue([{ insertId: 42 }]) คือ stub: MySQL ตอบเป็น array และตัวแรกมี id ใหม่
  3. spy ตรวจว่า SQL มี INSERT INTO tasks และ ค่า ถูกส่งแยกเป็น parameter (ไม่ต่อลงในข้อความ) และเรียงถูกลำดับ

beforeEach รันก่อนทุก test และ vi.clearAllMocks() ลืมการเรียกของ test ก่อนหน้า เพื่อให้ test ไม่กระทบกัน

Create the file tests/taskService.test.js (in the Explorer: unit › tests › taskService.test.js; right-click the folder, then New File). Paste the code into it and save.

import { beforeEach, describe, expect, it, vi } from 'vitest';
import { db } from '../src/server/db.js';
import { createTask, ValidationError } from '../src/server/taskService.js';

// Replace the real database file with a fake that only has a query function we control.
vi.mock('../src/server/db.js', () => ({ db: { query: vi.fn() } }));

beforeEach(() => {
  vi.clearAllMocks();
});

describe('createTask', () => {
  it('inserts the task with placeholders and returns it with its new id', async () => {
    db.query.mockResolvedValue([{ insertId: 42 }]);

    const task = await createTask({ title: '  Buy milk ', priority: 3 });

    expect(db.query).toHaveBeenCalledTimes(1);
    const [sql, params] = db.query.mock.calls[0];
    expect(sql).toMatch(/INSERT INTO tasks/);
    expect(params).toEqual(['Buy milk', 3]);
    expect(task).toEqual({ id: 42, title: 'Buy milk', priority: 3, done: 0 });
  });
});
