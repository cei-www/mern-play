Step B.5: Test the error paths

Most bugs hide where things go wrong, and that is where tests are often missing. createTask has two error paths:

  • the input is invalid: it must throw ValidationError and never call the database. The spy proves it with not.toHaveBeenCalled();
  • the database fails: the error must reach the caller (so the route can answer 500) and not be swallowed. mockRejectedValue makes the stub fail.

For code that returns a promise, write await expect(promise).rejects.toThrow(...), and mark the test function async.

บั๊กส่วนใหญ่ซ่อนอยู่ตรงที่เรื่องผิดพลาด และตรงนั้นมักไม่มี test createTask มีสอง error path:

  • ข้อมูลไม่ถูกต้อง: ต้อง throw ValidationError และ ห้ามเรียกฐานข้อมูล spy พิสูจน์ได้ด้วย not.toHaveBeenCalled()
  • ฐานข้อมูลล้มเหลว: error ต้องไปถึงผู้เรียก (เพื่อให้ route ตอบ 500 ได้) และไม่ถูกกลืน mockRejectedValue ทำให้ stub ล้มเหลว

สำหรับโค้ดที่คืน promise ให้เขียน await expect(promise).rejects.toThrow(...) และทำเครื่องหมายฟังก์ชัน test เป็น async

Edit tests/taskService.test.js (in the Explorer: unit › tests › taskService.test.js). Add the code at the end of the file.

describe('createTask errors', () => {
  it('rejects an invalid task and never touches the database', async () => {
    await expect(createTask({ title: '' })).rejects.toThrow(ValidationError);
    expect(db.query).not.toHaveBeenCalled();
  });

  it('lets a database failure through to the caller', async () => {
    db.query.mockRejectedValue(new Error('connection lost'));
    await expect(createTask({ title: 'Buy milk' })).rejects.toThrow('connection lost');
  });
});
Hint

ValidationError is already imported at the top of the file by the code of step B.4.

Solution

In tests/taskService.test.js (at the end of the file):

describe('createTask errors', () => {
  it('rejects an invalid task and never touches the database', async () => {
    await expect(createTask({ title: '' })).rejects.toThrow(ValidationError);
    expect(db.query).not.toHaveBeenCalled();
  });

  it('lets a database failure through to the caller', async () => {
    db.query.mockRejectedValue(new Error('connection lost'));
    await expect(createTask({ title: 'Buy milk' })).rejects.toThrow('connection lost');
