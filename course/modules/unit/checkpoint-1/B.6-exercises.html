Step B.6: Checkpoint 1: two exercises

About 15 minutes. Both exercises are optional. Try first, then the hint, and only then the solution. The check puts bugs into the code and wants your tests to catch them.

ใช้เวลาประมาณ 15 นาที โจทย์ทั้งสองข้อเป็นทางเลือก ลองทำเองก่อน แล้วค่อยเปิด hint และเปิด solution เป็นลำดับสุดท้าย การตรวจจะใส่บั๊กลงในโค้ดและต้องการให้ test ของคุณจับได้

Exercise 1 (easier): formatDueDate

Write tests for formatDueDate(dueDate, now) in src/server/dates.js. It turns a due date into text: "No due date", "Due today", "Overdue (date)" for a past day and "Due date" for a future day. The second argument now lets you fix "today", so the tests give the same result on every day: new Date('2026-06-15T10:00:00Z'). Cover no date, today, and a past date (a future date too, if you like).

เขียน test ให้ formatDueDate(dueDate, now) ใน src/server/dates.js มันแปลงวันครบกำหนดเป็นข้อความ: "No due date", "Due today", "Overdue (วันที่)" สำหรับวันในอดีต และ "Due วันที่" สำหรับวันในอนาคต อาร์กิวเมนต์ที่สอง now ให้คุณกำหนด "วันนี้" ตายตัว test จึงให้ผลเหมือนเดิมทุกวัน: new Date('2026-06-15T10:00:00Z') ครอบคลุม ไม่มีวันที่ วันนี้ และวันในอดีต (ถ้าชอบจะเพิ่มวันในอนาคตด้วยก็ได้)

Create the file tests/formatDueDate.test.js (in the Explorer: unit › tests › formatDueDate.test.js), then write your tests in it.

Hint

Make a constant now at the top and pass it to every call. Dates are given as text like '2026-06-10'. Look at the function to see the exact words it returns.

Solution

In tests/formatDueDate.test.js (create the file):

import { describe, expect, it } from 'vitest';
import { formatDueDate } from '../src/server/dates.js';

// A fixed "now", so the tests give the same result on every day.
const now = new Date('2026-06-15T10:00:00Z');

describe('formatDueDate', () => {
  it('says there is no due date', () => {
    expect(formatDueDate(null, now)).toBe('No due date');
  });

  it('says "Due today" for today', () => {
    expect(formatDueDate('2026-06-15', now)).toBe('Due today');
  });

  it('says "Overdue" and the date for a day in the past', () => {
    expect(formatDueDate('2026-06-10', now)).toBe('Overdue (2026-06-10)');
  });

  it('says "Due" and the date for a day in the future', () => {
    expect(formatDueDate('2026-06-20', now)).toBe('Due 2026-06-20');
  });
});

Exercise 2 (harder): isOverdue with it.each

Write tests for isOverdue(task, now) in src/server/dates.js with it.each and four cases: no due date, due yesterday and still open, due yesterday but done, and due today. Only the second one is overdue. Each row of your table holds a name, a task and the expected answer.

เขียน test ให้ isOverdue(task, now) ใน src/server/dates.js ด้วย it.each และสี่กรณี: ไม่มีวันครบกำหนด ครบกำหนดเมื่อวานและยังไม่เสร็จ ครบกำหนดเมื่อวานแต่เสร็จแล้ว และครบกำหนดวันนี้ มีเฉพาะกรณีที่สองที่เกินกำหนด แต่ละแถวในตารางมีชื่อ task และคำตอบที่คาด

Create the file tests/isOverdue.test.js (in the Explorer: unit › tests › isOverdue.test.js), then write your tests in it.

Hint

A task is an object like { due_date: '2026-06-14', done: 0 }. A row looks like ['name', task, expected] and the test function gets the three values as parameters.

Solution

In tests/isOverdue.test.js (create the file):

import { describe, expect, it } from 'vitest';
import { isOverdue } from '../src/server/dates.js';

const now = new Date('2026-06-15T10:00:00Z');

describe('isOverdue', () => {
  it.each([
    ['has no due date', { due_date: null, done: 0 }, false],
    ['was due yesterday and is still open', { due_date: '2026-06-14', done: 0 }, true],
    ['was due yesterday but is done', { due_date: '2026-06-14', done: 1 }, false],
    ['is due today', { due_date: '2026-06-15', done: 0 }, false],
  ])('a task that %s', (_name, task, expected) => {
    expect(isOverdue(task, now)).toBe(expected);
  });
});
