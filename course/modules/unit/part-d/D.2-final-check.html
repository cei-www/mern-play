Step D.2: Final check

The last check looks at your whole test suite:

  1. every test passes, and there are enough of them;
  2. coverage reaches the threshold in vitest.config.js (40%);
  3. your tests catch the bugs: the check puts about a dozen small bugs into the code, one at a time (in a copy, not in your files), and runs your tests. At most two may slip through.

It takes a minute or two, because it runs the tests many times. If a bug slips through, the message names the missing case: go back to the step of that file and add a test. The checkpoint exercises are not needed to pass.

การตรวจสุดท้ายดูชุด test ทั้งหมดของคุณ:

  1. ทุก test ผ่าน และมีจำนวนมากพอ
  2. coverage ถึงเกณฑ์ใน vitest.config.js
  3. test ของคุณจับบั๊กได้: การตรวจใส่บั๊กเล็ก ๆ ราวสิบกว่าตัวลงในโค้ดทีละตัว (ในสำเนา ไม่ใช่ไฟล์ของคุณ) แล้วรัน test ของคุณ หลุดได้ไม่เกินสองตัว

ใช้เวลาหนึ่งถึงสองนาที เพราะมันรัน test หลายครั้ง ถ้ามีบั๊กหลุด ข้อความจะบอกกรณีที่ขาด: กลับไปที่ step ของไฟล์นั้นแล้วเพิ่ม test โจทย์ใน checkpoint ไม่จำเป็นต่อการผ่าน

Hint

Run npm test and npm run coverage yourself first. If they pass, the check will reach the bug part. Do not change files in src: the check tells you if you did.
