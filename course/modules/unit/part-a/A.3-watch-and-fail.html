Step A.3: Watch mode and reading a failure

Start Vitest in watch mode. It keeps running and runs the tests again each time you save, so you get an answer in a second:

เริ่ม Vitest ใน watch mode มันทำงานค้างไว้และรัน test ใหม่ทุกครั้งที่คุณบันทึก จึงได้คำตอบภายในหนึ่งวินาที:

npm run test:watch

Leave it running (use q to quit when you are done). Now make a test fail on purpose: in tests/orderBy.test.js change 'ORDER BY t.created_at ASC' to 'ORDER BY t.created_at DESC' and save. Read the failure:

  • the line FAIL and the test name tell you which test;
  • Expected is what your test wanted, Received is what the code returned: here you see the difference with ASC and DESC;
  • the arrow > in the code excerpt shows the line of the failing expect.

When a test fails there are two possible reasons: the code is wrong, or the test is wrong. Here the test is wrong, so put ASC back and save. It turns green by itself.

Now add two more tests, with different input. They go in a second describe block at the end of the file:

ปล่อยให้มันทำงานค้างไว้ (กด q เพื่อออกเมื่อเสร็จ) จากนั้น ทำให้ test ล้มโดยตั้งใจ: ใน tests/orderBy.test.js เปลี่ยน 'ORDER BY t.created_at ASC' เป็น 'ORDER BY t.created_at DESC' แล้วบันทึก อ่านความล้มเหลว:

  • บรรทัด FAIL และชื่อ test บอกว่า test ไหน
  • Expected คือที่ test ของคุณต้องการ Received คือที่โค้ดคืนมา: ตรงนี้เห็นความต่างระหว่าง ASC กับ DESC
  • ลูกศร > ในโค้ดตัวอย่างชี้บรรทัด expect ที่ล้ม

เมื่อ test ล้ม มีสองสาเหตุที่เป็นไปได้: โค้ดผิด หรือ test ผิด ตรงนี้ test ผิด จึงใส่ ASC กลับแล้วบันทึก มันจะกลับเป็นสีเขียวเอง

ตอนนี้เพิ่มอีกสอง test ด้วยข้อมูลต่างออกไป ใส่ใน describe บล็อกที่สองท้ายไฟล์:

Edit tests/orderBy.test.js (in the Explorer: unit › tests › orderBy.test.js). Add the code at the end of the file.

describe('buildOrderBy with a choice', () => {
  it('sorts by priority, highest first', () => {
    expect(buildOrderBy('priority', 'desc')).toBe('ORDER BY t.priority DESC');
  });

  it('sorts by title, A to Z', () => {
    expect(buildOrderBy('title', 'asc')).toBe('ORDER BY t.title ASC');
  });
});

Both new tests pass. Check the whole file with the button below, or type tutorial check A.3.

ทั้งสอง test ใหม่ผ่าน ตรวจทั้งไฟล์ด้วยปุ่มด้านล่าง หรือพิมพ์ tutorial check A.3

Hint

If the new tests are not found, check that the new describe is outside the closing }); of the first one, at the end of the file.
