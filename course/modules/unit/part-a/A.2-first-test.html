Step A.2: Your first test

The function buildOrderBy(sort, order) in src/server/orderBy.js makes the ORDER BY part of the task list query. It is a pure function: the same input always gives the same output, and it touches nothing outside itself. These are the easiest functions to test.

Create a test file for it. Four tools are in the code below: describe groups tests, it is one test (its text says what must be true), expect(...) takes the real value and .toBe(...) says what it must be. They come from 'vitest'.

ฟังก์ชัน buildOrderBy(sort, order) ใน src/server/orderBy.js สร้างส่วน ORDER BY ของ query รายการ task มันเป็น pure function: ข้อมูลเข้าเหมือนเดิมให้ผลลัพธ์เหมือนเดิมเสมอ และไม่แตะอะไรนอกตัวมัน ฟังก์ชันแบบนี้ทดสอบง่ายที่สุด

สร้างไฟล์ test ให้มัน โค้ดด้านล่างมีเครื่องมือสี่อย่าง: describe จัดกลุ่ม test, it คือหนึ่ง test (ข้อความบอกว่าต้องเป็นจริงอะไร), expect(...) รับค่าจริง และ .toBe(...) บอกว่าต้องเป็นค่าอะไร ทั้งหมดนำเข้าจาก 'vitest'

Create the file tests/orderBy.test.js (in the Explorer: unit › tests › orderBy.test.js; right-click the folder, then New File). Paste the code into it and save.

import { describe, expect, it } from 'vitest';
import { buildOrderBy } from '../src/server/orderBy.js';

describe('buildOrderBy', () => {
  it('sorts by creation time, oldest first, when nothing is given', () => {
    // Arrange: nothing to prepare, the function has defaults.
    // Act
    const clause = buildOrderBy();
    // Assert
    expect(clause).toBe('ORDER BY t.created_at ASC');
  });
});

Run it in the terminal:

รันใน terminal:

npx vitest run tests/orderBy.test.js

You should see 1 passed. A test that has never failed has not proved much: in the next step you will see one fail.

ควรเห็น 1 passed test ที่ไม่เคยล้มยังพิสูจน์อะไรไม่ได้มาก step ถัดไปคุณจะได้เห็นมันล้ม

Hint

The import path is relative to the test file: ../src/server/orderBy.js (up one folder, then into src). A name with a typo gives "is not a function" or "Failed to resolve import".
