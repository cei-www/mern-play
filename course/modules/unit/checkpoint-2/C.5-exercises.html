Exercise 3 (harder): markDone with a mocked database

Write tests for markDone(id, done) in src/server/taskService.js. It updates the task through db.query and returns { id, done }; when no task has that id (affectedRows is 0) it throws NotFoundError. Mock the database as in step B.4. Cover: marking as done, marking as not done (markDone(7, false)), and a task that does not exist. Check the parameters of the query too: they carry the done flag and the id.

เขียน test ให้ markDone(id, done) ใน src/server/taskService.js มันอัปเดต task ผ่าน db.query และคืน { id, done } เมื่อไม่มี task ที่มี id นั้น (affectedRows เป็น 0) มัน throw NotFoundError mock ฐานข้อมูลเหมือน step B.4 ครอบคลุม: ทำเครื่องหมายว่าเสร็จ ทำเครื่องหมายว่ายังไม่เสร็จ (markDone(7, false)) และ task ที่ไม่มีอยู่ ตรวจ parameter ของ query ด้วย: มันพา flag done และ id ไป

Create the file tests/markDone.test.js (in the Explorer: unit › tests › markDone.test.js), then write your tests in it.

Hint

The stub for a found task is db.query.mockResolvedValue([{ affectedRows: 1 }]), for a missing one [{ affectedRows: 0 }]. The parameters are db.query.mock.calls[0][1].

Solution

In tests/markDone.test.js (create the file):

import { beforeEach, describe, expect, it, vi } from 'vitest';
import { db } from '../src/server/db.js';
import { markDone, NotFoundError } from '../src/server/taskService.js';

vi.mock('../src/server/db.js', () => ({ db: { query: vi.fn() } }));

beforeEach(() => {
  vi.clearAllMocks();
});

describe('markDone', () => {
  it('marks a task as done', async () => {
    db.query.mockResolvedValue([{ affectedRows: 1 }]);

    const result = await markDone(7);

    expect(result).toEqual({ id: 7, done: 1 });
    expect(db.query.mock.calls[0][1]).toEqual([1, 1, 7]);
  });

  it('marks a task as not done again', async () => {
    db.query.mockResolvedValue([{ affectedRows: 1 }]);

    const result = await markDone(7, false);

    expect(result).toEqual({ id: 7, done: 0 });
    expect(db.query.mock.calls[0][1]).toEqual([0, 0, 7]);
  });

  it('throws NotFoundError when no task has that id', async () => {
    db.query.mockResolvedValue([{ affectedRows: 0 }]);

    await expect(markDone(99)).rejects.toThrow(NotFoundError);
  });
});

Exercise 4 (harder): TaskItem: toggling and the checked box

Write tests for TaskItem in src/client/components/TaskItem.jsx: clicking the checkbox calls onToggle with the id of the task; an open task shows an empty box; a done task shows a checked box. Find the box by its role, as a user would.

เขียน test ให้ TaskItem ใน src/client/components/TaskItem.jsx: การคลิก checkbox เรียก onToggle พร้อม id ของ task task ที่ยังไม่เสร็จแสดงกล่องว่าง task ที่เสร็จแสดงกล่องที่ติ๊กแล้ว หากล่องด้วย role ของมัน เหมือนที่ผู้ใช้ทำ

Create the file tests/TaskItem.test.jsx (in the Explorer: unit › tests › TaskItem.test.jsx), then write your tests in it.

Hint

getByRole('checkbox'), then toBeChecked() or not.toBeChecked(). For the click use userEvent and a vi.fn() as onToggle.

Solution

In tests/TaskItem.test.jsx (create the file):

import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { describe, expect, it, vi } from 'vitest';
import TaskItem from '../src/client/components/TaskItem.jsx';

const open = { id: 5, title: 'Buy milk', done: 0 };
const finished = { id: 6, title: 'Walk the dog', done: 1 };

describe('TaskItem toggling', () => {
  it('calls onToggle with the id of the task when the box is clicked', async () => {
    const user = userEvent.setup();
    const onToggle = vi.fn();
    render(<TaskItem task={open} onToggle={onToggle} onDelete={() => {}} />);

    await user.click(screen.getByRole('checkbox'));

    expect(onToggle).toHaveBeenCalledWith(5);
  });

  it('shows an open task with an empty box', () => {
    render(<TaskItem task={open} onToggle={() => {}} onDelete={() => {}} />);
    expect(screen.getByRole('checkbox')).not.toBeChecked();
  });

  it('shows a done task with a checked box', () => {
    render(<TaskItem task={finished} onToggle={() => {}} onDelete={() => {}} />);
    expect(screen.getByRole('checkbox')).toBeChecked();
  });
});
