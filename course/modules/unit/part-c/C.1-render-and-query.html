Step C.1: Render a component and find things

Now the React components in src/client/components. A component test has the same three parts, with Testing Library doing the work:

  • render(<Summary tasks={...} />) puts the component on a simulated page (Arrange and Act in one);
  • screen finds things the way a user sees them: getByText('1 of 3 done') by visible text, getByRole('button', { name: 'Delete' }) by what it is (a button) and its accessible name, getByLabelText('Title') for form fields;
  • expect(...).toBeInTheDocument() comes from jest-dom, which adds readable checks for pages.

Prefer getByRole: it forces the page to be usable with a screen reader, because that is how roles work. Use getByText when there is no role for it. The file ends in .test.jsx because it contains JSX and needs the simulated browser.

ต่อไปคือ React component ใน src/client/components test ของ component มีสามส่วนเหมือนเดิม โดยมี Testing Library ทำงานให้:

  • render(<Summary tasks={...} />) วาง component บนหน้าจำลอง (Arrange และ Act ในคราวเดียว)
  • screen หาของแบบที่ ผู้ใช้ มองเห็น: getByText('1 of 3 done') จากข้อความที่เห็น, getByRole('button', { name: 'Delete' }) จากสิ่งที่มัน เป็น (ปุ่ม) และชื่อที่ screen reader อ่าน, getByLabelText('Title') สำหรับช่องกรอก
  • expect(...).toBeInTheDocument() มาจาก jest-dom ที่เพิ่มการตรวจที่อ่านง่ายสำหรับหน้าเว็บ

ใช้ getByRole ก่อน: มันบังคับให้หน้าเว็บใช้กับ screen reader ได้ เพราะ role ทำงานแบบนั้น ใช้ getByText เมื่อไม่มี role ที่เหมาะ ไฟล์ลงท้าย .test.jsx เพราะมี JSX และต้องใช้เบราว์เซอร์จำลอง

Create the file tests/rendering.test.jsx (in the Explorer: unit › tests › rendering.test.jsx; right-click the folder, then New File). Paste the code into it and save.

import { render, screen } from '@testing-library/react';
import { describe, expect, it } from 'vitest';
import Summary from '../src/client/components/Summary.jsx';
import TaskItem from '../src/client/components/TaskItem.jsx';

describe('Summary', () => {
  it('says how many tasks are done', () => {
    const tasks = [
      { id: 1, done: 1 },
      { id: 2, done: 0 },
      { id: 3, done: 0 },
    ];

    render(<Summary tasks={tasks} />);

    expect(screen.getByText('1 of 3 done')).toBeInTheDocument();
  });

  it('says 0 of 0 when there are no tasks', () => {
    render(<Summary tasks={[]} />);
    expect(screen.getByText('0 of 0 done')).toBeInTheDocument();
  });
});

describe('TaskItem', () => {
  it('shows the title and a Delete button', () => {
    render(<TaskItem task={{ id: 1, title: 'Buy milk', done: 0 }} onToggle={() => {}} onDelete={() => {}} />);

    expect(screen.getByText('Buy milk')).toBeInTheDocument();
    expect(screen.getByRole('button', { name: 'Delete' })).toBeInTheDocument();
    expect(screen.getByRole('checkbox', { name: 'Mark "Buy milk" as done' })).toBeInTheDocument();
  });
});
