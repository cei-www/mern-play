Step 2.3: Grid: groups and list

Grid lays things out in rows and columns. The page has two parts side by side: the groups on the left and the tasks on the right.

  • grid turns the element into a grid.
  • grid-cols-[14rem_1fr] makes two columns: a fixed 14rem for the groups and 1fr (all that is left) for the tasks. The square brackets are an arbitrary value: any CSS value you need, with underscores for spaces.
  • gap-6 is the space between the columns.

Grid จัดวางเป็นแถว และ คอลัมน์ หน้าเว็บมีสองส่วนอยู่ข้างกัน: group ทางซ้ายและ task ทางขวา

  • grid ทำให้องค์ประกอบเป็น grid
  • grid-cols-[14rem_1fr] สร้างสองคอลัมน์: 14rem คงที่สำหรับ group และ 1fr (ที่เหลือทั้งหมด) สำหรับ task วงเล็บเหลี่ยมคือ arbitrary value: ค่า CSS ใดก็ได้ที่ต้องการ โดยใช้ underscore แทนช่องว่าง
  • gap-6 คือช่องว่างระหว่างคอลัมน์

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s2-3-layout-grid and @tutorial:end s2-3-layout-grid, in the class list of the div that holds the aside and the section.

'grid grid-cols-[14rem_1fr] gap-6',
