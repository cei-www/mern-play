Step 2.2: Flex: header and rows

Flexbox lays children out in a row. flex turns an element into a flex box and its children line up horizontally. Then:

  • items-center centers the children vertically; justify-between pushes the first child to the left and the last to the right.
  • gap-3 puts equal space between children.
  • flex-wrap lets children go to the next line when there is no room.
  • flex-col stacks children in a column instead.

Use it in six places: the page header (title left, tabs right), the tabs, the task row, the form, the group buttons and the sort bar.

Flexbox จัดลูกให้เรียงเป็นแถว flex ทำให้องค์ประกอบเป็นกล่อง flex และลูกเรียงแนวนอน แล้ว:

  • items-center จัดลูกให้กึ่งกลางแนวตั้ง justify-between ดันลูกตัวแรกไปซ้ายและตัวสุดท้ายไปขวา
  • gap-3 ใส่ช่องว่างเท่ากันระหว่างลูก
  • flex-wrap ให้ลูกลงบรรทัดถัดไปเมื่อที่ไม่พอ
  • flex-col วางลูกซ้อนเป็นคอลัมน์แทน

ใช้ใน 6 ที่: header ของหน้า (ชื่อซ้าย tab ขวา), tab, แถว task, ฟอร์ม, ปุ่ม group และแถบเรียงลำดับ
