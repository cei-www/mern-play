Step 2.4: Container, maximum width, centering

On a wide screen the page stretches edge to edge, which is hard to read. Limit its width and center it: max-w-4xl (a maximum width of 56rem) and mx-auto (automatic left and right margins, which center a block).

To see the effect you need a wide window: press the "open in a new browser tab" arrow of the Preview tab and widen the browser.

บนจอกว้าง หน้าเว็บจะยืดเต็มขอบ ซึ่งอ่านยาก จำกัดความกว้างและจัดกึ่งกลาง: max-w-4xl (ความกว้างสูงสุด 56rem) และ mx-auto (margin ซ้ายขวาอัตโนมัติ ซึ่งทำให้บล็อกอยู่กึ่งกลาง)

เพื่อเห็นผล ต้องใช้หน้าต่างกว้าง: กดลูกศร "เปิดในแท็บเบราว์เซอร์ใหม่" ของ tab Preview แล้วขยายเบราว์เซอร์

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s2-4-container and @tutorial:end s2-4-container, in the class list of main (below the padding you wrote in step 2.1).
