Step 2.1: Padding, margin and gap

Spacing is the first thing that makes a page feel designed. Tailwind uses one scale for all of it: the number is a step of 0.25rem (4px at normal size). So p-3 is 0.75rem of padding and mb-4 is 1rem of margin at the bottom.

ClassMeaning
p-3padding on all sides
px-3 / py-1padding left and right / top and bottom
m-2 mb-4 mt-2margin (all sides, bottom, top)
gap-2space between the children of a flex or grid box (next step)

Give the page, every task row and the form some room.

ระยะห่างคือสิ่งแรกที่ทำให้หน้าเว็บดูมีการออกแบบ Tailwind ใช้สเกลเดียวกับทุกอย่าง: ตัวเลขคือหนึ่งขั้นของ 0.25rem (4px ที่ขนาดปกติ) ดังนั้น p-3 คือ padding 0.75rem และ mb-4 คือ margin ด้านล่าง 1rem

Classความหมาย
p-3padding ทุกด้าน
px-3 / py-1padding ซ้าย-ขวา / บน-ล่าง
m-2 mb-4 mt-2margin (ทุกด้าน, ล่าง, บน)
gap-2ช่องว่างระหว่างลูกของกล่อง flex หรือ grid (step ถัดไป)

เพิ่มพื้นที่ให้หน้าเว็บ แถว task ทุกแถว และฟอร์ม

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s2-1-page-spacing and @tutorial:end s2-1-page-spacing, in the class list of main.

'p-3',

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s2-1-row-spacing and @tutorial:end s2-1-row-spacing, in the class list of the li.

'mb-2 p-3',

Edit client/src/components/TaskForm.jsx (in the Explorer: style › client › src › components › TaskForm.jsx). Write the code between the comments @tutorial:begin s2-1-form-spacing and @tutorial:end s2-1-form-spacing, in the class list of the form.

'mb-4',
