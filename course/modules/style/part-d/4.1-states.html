Step 4.1: Hover, focus and active

A control should answer the user. CSS calls these answers states, and Tailwind writes them as a variant: a prefix and a colon in front of a class. The class applies only in that state.

  • hover:bg-slate-100: when the mouse is over it.
  • focus-visible:outline-2: when it has keyboard focus (and only then). This is what lets keyboard users see where they are. Never remove it without a replacement.
  • active:scale-95: while it is pressed (it shrinks a little).

Add all three to the tab buttons and the group buttons. The zone also holds a condition: the selected tab or group gets the brand color (view === name && '...').

ตัวควบคุมควร ตอบสนอง ผู้ใช้ CSS เรียกการตอบสนองเหล่านี้ว่า state และ Tailwind เขียนเป็น variant: คำนำหน้าและเครื่องหมายทวิภาคหน้า class class นั้นทำงานเฉพาะใน state นั้น

  • hover:bg-slate-100: เมื่อเมาส์อยู่เหนือมัน
  • focus-visible:outline-2: เมื่อมี keyboard focus (และเฉพาะตอนนั้น) ทำให้ผู้ใช้คีย์บอร์ดเห็นว่าอยู่ตรงไหน อย่าลบออกโดยไม่มีอะไรมาแทน
  • active:scale-95: ขณะถูกกด (หดลงเล็กน้อย)

เพิ่มทั้งสามอย่างให้ปุ่ม tab และปุ่ม group ใน zone ยังมีเงื่อนไขด้วย: tab หรือ group ที่เลือกได้สี brand (view === name && '...')

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s4-1-tab-states and @tutorial:end s4-1-tab-states, in the class list of the tab button.

'hover:bg-slate-100 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-brand-500 active:scale-95',
view === name && 'border-brand-600 bg-brand-600 text-white hover:bg-brand-600',

Edit client/src/components/GroupFilter.jsx (in the Explorer: style › client › src › components › GroupFilter.jsx). Write the code between the comments @tutorial:begin s4-1-group-states and @tutorial:end s4-1-group-states, in the class list of the group button.

'hover:bg-slate-100 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-brand-500 active:scale-95',
value === group.id && 'border-brand-600 bg-brand-600 text-white hover:bg-brand-600',

Move the mouse over the buttons, press and hold one, and press Tab in the page to see the focus outline.
