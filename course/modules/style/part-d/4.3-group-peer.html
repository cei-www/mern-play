Step 4.3: group and peer

Sometimes the thing that changes is not the element you hover or click. Tailwind has two helpers for this.

  • group: mark a parent with group, and children can react to the parent's state with group-hover:. The Delete button of a row stays hidden (opacity-0) until the mouse is over the row (group-hover:opacity-100), and it also shows when it has focus (focus:opacity-100), so a keyboard user can reach it.
  • peer: mark an element with peer, and its next siblings can react with peer-checked:. The title comes right after the checkbox, so when the checkbox is ticked the title gets a line through it and a softer color, with no JavaScript.

บางครั้งสิ่งที่เปลี่ยนไม่ใช่องค์ประกอบที่คุณ hover หรือคลิก Tailwind มีตัวช่วยสองอย่าง

  • group: ติด group ที่ parent แล้วลูกจะตอบสนองต่อ state ของ parent ด้วย group-hover: ปุ่ม Delete ของแถวซ่อนอยู่ (opacity-0) จนกว่าเมาส์จะอยู่เหนือ แถว (group-hover:opacity-100) และแสดงเมื่อมี focus ด้วย (focus:opacity-100) ผู้ใช้คีย์บอร์ดจึงเข้าถึงได้
  • peer: ติด peer ที่องค์ประกอบหนึ่ง แล้ว พี่น้องที่ตามมา ตอบสนองด้วย peer-checked: ได้ ชื่อ task อยู่ถัดจาก checkbox พอดี เมื่อติ๊ก checkbox ชื่อจะมีเส้นขีดทับและสีอ่อนลง โดยไม่ใช้ JavaScript

Hover a row: Delete appears. Tick a task: its title is crossed out. Both work because of the order in the markup: the checkbox must come before the title.
