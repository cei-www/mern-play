Step 4.2: Focus rings and disabled buttons

Two more states for the form.

  • focus: (not focus-visible:) fits a text field: it shows when the field is clicked or tabbed into. focus:ring-2 draws a ring around it and focus:ring-brand-500/30 colors it with 30% opacity (the slash is an opacity modifier). focus:outline-none removes the default outline because the ring replaces it.
  • disabled: applies when the element has the disabled attribute. The Add button is disabled while the title is empty (the code disabled={!title.trim()} is already there).

อีกสอง state สำหรับฟอร์ม

  • focus: (ไม่ใช่ focus-visible:) เหมาะกับช่องข้อความ: แสดงเมื่อคลิกหรือกด Tab เข้าไปที่ช่อง focus:ring-2 วงแหวนรอบช่อง และ focus:ring-brand-500/30 ใส่สีด้วยความทึบ 30% (เครื่องหมาย / คือ opacity modifier) focus:outline-none เอา outline เริ่มต้นออก เพราะวงแหวนมาแทน
  • disabled: ใช้เมื่อองค์ประกอบมี attribute disabled ปุ่ม Add ถูก disable ขณะ title ว่าง (โค้ด disabled={!title.trim()} มีอยู่แล้ว)

Hint

A disabled button should look disabled and not invite a click: opacity-50 fades it, cursor-not-allowed changes the mouse pointer.
