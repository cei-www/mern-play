Step 3.6: Checkpoint 1: two exercises

About 15 minutes. Both exercises are optional. Try first, then the hint, and only then the solution. The check only reads your classes: look at Preview to see whether you like the result.

ใช้เวลาประมาณ 15 นาที โจทย์ทั้งสองข้อเป็นทางเลือก ลองทำเองก่อน แล้วค่อยเปิด hint และเปิด solution เป็นลำดับสุดท้าย การตรวจอ่านแค่ class ของคุณ ดูที่ Preview เองว่าพอใจกับผลลัพธ์หรือไม่

Exercise 1 (easier): the Add button

Give the Add button of the form a primary look: a colored background (use your brand color), white text, rounded corners and some padding. The classes of step 4.2 for the disabled state come later and are already written.

ทำให้ปุ่ม Add ของฟอร์มดูเป็นปุ่มหลัก: พื้นหลังมีสี (ใช้สี brand ของคุณ) ตัวอักษรขาว มุมมน และมี padding class สำหรับสถานะ disabled ของ step 4.2 อยู่ต่อจากนี้และเขียนไว้แล้ว

Edit client/src/components/TaskForm.jsx (in the Explorer: style › client › src › components › TaskForm.jsx). Write the code between the comments @tutorial:begin exercise-1-add-button and @tutorial:end exercise-1-add-button, in the class list of the Add button.

Hint

Four ideas: bg-brand-600, text-white, rounded, px-4 py-1.5.

Solution

In client/src/components/TaskForm.jsx, between the comments of exercise-1-add-button:

'rounded bg-brand-600 px-4 py-1.5 font-medium text-white',

Exercise 2 (harder): priority colors

Color the priority badge by priority: high red, medium yellow, low green (a light background and a dark text of the same color, like the group badge). Each color is a condition with &&: task.priority === 3 && '...'.

ใส่สีให้ badge ของ priority ตามระดับ: high สีแดง medium สีเหลือง low สีเขียว (พื้นอ่อนและตัวอักษรเข้มสีเดียวกัน เหมือน badge ของ group) แต่ละสีเป็นเงื่อนไขด้วย &&: task.priority === 3 && '...'

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin exercise-2-priority-colors and @tutorial:end exercise-2-priority-colors, in the class list of the priority span, below your classes of step 3.5.

Hint

cx ignores false, so one list can hold three conditions: only the one that is true adds its classes. Priority 3 is high, 2 medium, 1 low.

Solution

In client/src/components/TaskItem.jsx, between the comments of exercise-2-priority-colors:

task.priority === 3 && 'bg-red-100 text-red-800',
task.priority === 2 && 'bg-yellow-100 text-yellow-800',
task.priority === 1 && 'bg-green-100 text-green-800',
