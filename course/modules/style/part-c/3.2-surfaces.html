Step 3.2: Cards and surfaces

A surface is a box with a background, a border and a shadow. Make each task a card:

  • bg-white a white background
  • border border-slate-200 a thin soft border (border sets the width, the second class the color)
  • rounded-lg rounded corners
  • shadow-sm a small shadow

Put a soft gray behind the whole page (bg-slate-50 with min-h-screen, so it fills the window), and give the rows of the History tab a lighter version of the card.

surface คือกล่องที่มีพื้นหลัง เส้นขอบ และเงา ทำให้แต่ละ task เป็นการ์ด:

  • bg-white พื้นหลังสีขาว
  • border border-slate-200 เส้นขอบบางสีอ่อน (border กำหนดความหนา class ที่สองกำหนดสี)
  • rounded-lg มุมมน
  • shadow-sm เงาเล็ก ๆ

ใส่สีเทาอ่อนด้านหลังทั้งหน้า (bg-slate-50 กับ min-h-screen เพื่อให้เต็มหน้าต่าง) และทำให้แถวของ tab History เป็นการ์ดแบบเบากว่า
