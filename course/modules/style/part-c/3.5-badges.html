Step 3.5: Badges

A badge is a small pill of text. Combine what you know: rounded-full for the pill shape, a light background (bg-sky-100), dark text of the same family (text-sky-800), small type (text-xs font-medium) and a little padding (px-2 py-0.5; the dot is part of the number, 0.5 is half a step).

Style the group badge. For the priority badge write the shape and the type now; the colors by priority are Exercise 2 of the checkpoint.

badge คือแคปซูลข้อความเล็ก ๆ รวมสิ่งที่รู้แล้ว: rounded-full เพื่อทรงแคปซูล พื้นอ่อน (bg-sky-100) ตัวอักษรเข้มของตระกูลสีเดียวกัน (text-sky-800) ตัวเล็ก (text-xs font-medium) และ padding เล็กน้อย (px-2 py-0.5 จุดเป็นส่วนของตัวเลข 0.5 คือครึ่งขั้น)

จัดสไตล์ badge ของ group ส่วน badge ของ priority เขียนรูปทรงและตัวอักษรตอนนี้ ส่วน สี ตาม priority เป็นโจทย์ข้อ 2 ของ checkpoint

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s3-5-group-badge and @tutorial:end s3-5-group-badge, in the class list of the span that shows the group name.

'rounded-full bg-sky-100 px-2 py-0.5 text-xs font-medium text-sky-800',

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s3-5-priority-base and @tutorial:end s3-5-priority-base, in the class list of the span that shows the priority.

'rounded px-2 py-0.5 text-xs font-semibold uppercase',
