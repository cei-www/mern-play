Step 3.1: Typography

Text styling is a handful of classes you will use everywhere:

  • size: text-sm, text-base, text-xl, text-3xl ...
  • weight: font-medium, font-semibold, font-bold
  • letter spacing and line height: tracking-tight, leading-snug
  • color: text-slate-900 is a very dark gray, text-slate-500 a soft one. Colors come in named families (slate, red, sky ...) with shades from 50 (lightest) to 950 (darkest).

Give the title a tighter, darker look, the task title a medium weight (flex-1 also makes it take the free space of the row, pushing the other items to the right), and the due date a small, soft gray.

การจัดรูปตัวอักษรใช้ class ไม่กี่ตัวที่คุณจะใช้ทุกที่:

  • ขนาด: text-sm, text-base, text-xl, text-3xl ...
  • น้ำหนัก: font-medium, font-semibold, font-bold
  • ระยะห่างตัวอักษรและความสูงบรรทัด: tracking-tight, leading-snug
  • สี: text-slate-900 คือเทาเข้มมาก text-slate-500 คือเทาอ่อน สีมีเป็นตระกูลที่ตั้งชื่อ (slate, red, sky ...) และเฉดตั้งแต่ 50 (อ่อนสุด) ถึง 950 (เข้มสุด)

ทำให้ชื่อหน้าชิดและเข้มขึ้น ชื่อ task น้ำหนักปานกลาง (flex-1 ทำให้มันกินที่ว่างของแถวด้วย ดันรายการอื่นไปทางขวา) และวันครบกำหนดเป็นตัวเล็กสีเทาอ่อน

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s3-1-title-type and @tutorial:end s3-1-title-type, in the class list of the h1 (below the classes of step 1.4).

'tracking-tight text-slate-900',

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s3-1-title-weight and @tutorial:end s3-1-title-weight, in the class list of the span that shows the task title.

'flex-1 font-medium',

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s3-1-due-type and @tutorial:end s3-1-due-type, in the class list of the span that shows the due date.

'text-sm text-slate-500',
