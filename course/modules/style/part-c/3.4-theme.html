Step 3.4: Your own theme

Every project has its own colors. In Tailwind 4 you define them in your CSS with @theme. A variable named --color-brand-600 immediately gives you the classes text-brand-600, bg-brand-600, border-brand-600 and so on, with shades of your own.

The classes of later steps (the selected tab and group in step 4.1, the focus ring in step 4.2) use brand colors, so they need to exist. Define two shades and color the title with one of them.

ทุกโปรเจกต์มีสีของตัวเอง ใน Tailwind 4 คุณกำหนดสีใน CSS ของคุณด้วย @theme ตัวแปรชื่อ --color-brand-600 ทำให้ได้ class text-brand-600, bg-brand-600, border-brand-600 และอื่น ๆ ทันที ด้วยเฉดสีของคุณเอง

class ใน step ถัด ๆ ไป (tab และ group ที่เลือกใน step 4.1, วงแหวน focus ใน step 4.2) ใช้สี brand จึงต้องมีสีนี้ก่อน กำหนดสองเฉดและใช้เฉดหนึ่งกับชื่อหน้า

Edit client/src/index.css (in the Explorer: style › client › src › index.css). Write the code between the comments @tutorial:begin s3-4-theme and @tutorial:end s3-4-theme (below the import).

@theme {
  --color-brand-500: #6366f1;
  --color-brand-600: #4f46e5;
}

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s3-4-title-brand and @tutorial:end s3-4-title-brand, in the class list of the h1.

'text-brand-600',

Change the two color codes to any colors you like (for example a green: #16a34a and #15803d) and watch the page change everywhere at once. Put the lesson colors back when you are done.

เปลี่ยนรหัสสีทั้งสองเป็นสีที่คุณชอบ (เช่นสีเขียว: #16a34a และ #15803d) และดูหน้าเว็บเปลี่ยนทุกที่พร้อมกัน แล้วใส่สีของบทเรียนกลับเมื่อเสร็จ

The app is in the Preview tab (port App (for Tailwind)). It reloads by itself when you save.

แอปอยู่ใน tab Preview (พอร์ต App (for Tailwind)) และโหลดใหม่เองเมื่อคุณบันทึก

Open the app in Preview

Hint

The variable name must start with --color-. The part after it (brand-600) is the name you use in classes.

  --color-brand-600: #4f46e5;
