Step 3.3: Buttons and fields

Tailwind's reset removed the look of buttons and inputs, so you style them yourself. A simple pattern that works well: a border, rounded corners, a white background and padding.

Style the two tab buttons, the group buttons and the title field of the form. Note min-w-48 flex-1 on the field: it can shrink to 12rem and grows to take the free space of the form row.

reset ของ Tailwind ลบหน้าตาของปุ่มและ input ออก คุณจึงจัดสไตล์เอง รูปแบบง่าย ๆ ที่ใช้ได้ดี: เส้นขอบ มุมมน พื้นขาว และ padding

จัดสไตล์ปุ่ม tab สองปุ่ม ปุ่ม group และช่องชื่อของฟอร์ม สังเกต min-w-48 flex-1 ที่ช่อง: มันหดได้ถึง 12rem และขยายกินที่ว่างของแถวฟอร์ม

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s3-3-tab-base and @tutorial:end s3-3-tab-base, in the class list of the tab button.

'rounded border border-slate-300 bg-white px-3 py-1 capitalize',

Edit client/src/components/GroupFilter.jsx (in the Explorer: style › client › src › components › GroupFilter.jsx). Write the code between the comments @tutorial:begin s3-3-group-base and @tutorial:end s3-3-group-base, in the class list of the group button.

'rounded border border-slate-300 bg-white px-3 py-1 text-left',

Edit client/src/components/TaskForm.jsx (in the Explorer: style › client › src › components › TaskForm.jsx). Write the code between the comments @tutorial:begin s3-3-input-base and @tutorial:end s3-3-input-base, in the class list of the title input.

'min-w-48 flex-1 rounded border border-slate-300 bg-white px-2 py-1',
