Exercise 3 (easier): a finished task and a row that reacts

Make a completed task look finished: fade the whole row (opacity-60) when task.done is true. And make every row light up a little when the mouse is over it (hover:bg-slate-50).

ทำให้ task ที่ เสร็จแล้ว ดูเสร็จแล้ว: ทำให้ทั้งแถวจางลง (opacity-60) เมื่อ task.done เป็นจริง และทำให้ทุกแถวสว่างขึ้นเล็กน้อยเมื่อเมาส์อยู่เหนือ (hover:bg-slate-50)

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin exercise-3-done-row and @tutorial:end exercise-3-done-row, in the class list of the li.

Hint

task.done && 'opacity-60' gives the class only when the task is done. A plain string is always on.

Solution

In client/src/components/TaskItem.jsx, between the comments of exercise-3-done-row:

task.done && 'opacity-60',
'hover:bg-slate-50',

Exercise 4 (harder): the task list in columns

Show the tasks in one column on mobile and two columns from md. Make the ul a grid with a gap, and add the two-column rule for medium screens and up.

แสดง task เป็น หนึ่งคอลัมน์บนมือถือ และสองคอลัมน์ตั้งแต่ md ทำให้ ul เป็น grid ที่มี gap และเพิ่มกฎสองคอลัมน์สำหรับจอขนาดกลางขึ้นไป

Edit client/src/components/TaskList.jsx (in the Explorer: style › client › src › components › TaskList.jsx). Write the code between the comments @tutorial:begin exercise-4-task-columns and @tutorial:end exercise-4-task-columns, in the class list of the ul.

Hint

Mobile first: a plain grid gap-3 gives one column, and md:grid-cols-2 makes two from 768px. The rows keep their own bottom margin.

Solution

In client/src/components/TaskList.jsx, between the comments of exercise-4-task-columns:

'grid gap-3 md:grid-cols-2',
