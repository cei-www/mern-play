Step 1.3: Import Tailwind in your CSS

The last piece of the wiring is one line in your main CSS file. @import 'tailwindcss'; pulls in Tailwind's base styles (a reset that removes the browser's default look) and makes all the utility classes available. The file src/index.css is already loaded by main.jsx.

ชิ้นสุดท้ายของการเชื่อมต่อคือหนึ่งบรรทัดในไฟล์ CSS หลัก @import 'tailwindcss'; ดึงสไตล์พื้นฐานของ Tailwind (reset ที่ลบหน้าตาเริ่มต้นของเบราว์เซอร์) และทำให้ใช้ utility class ทั้งหมดได้ ไฟล์ src/index.css ถูกโหลดโดย main.jsx อยู่แล้ว

Edit client/src/index.css (in the Explorer: style › client › src › index.css). Write the code between the comments @tutorial:begin s1-3-css-import and @tutorial:end s1-3-css-import.

@import 'tailwindcss';

Save and look at Preview. The page changes: headings, lists and buttons lose their default look (the reset). That means Tailwind is connected.

บันทึกแล้วดู Preview หน้าเว็บเปลี่ยน: หัวข้อ รายการ และปุ่มหมดหน้าตาเริ่มต้น (จาก reset) แปลว่า Tailwind เชื่อมต่อแล้ว

Open the app in Preview

Hint

In CSS the line ends with a semicolon. If nothing changes, check that step 1.2 is saved and that the comment lines are still there.

Solution

In client/src/index.css, between the comments of s1-3-css-import:

@import 'tailwindcss';
