Step 1.5: See what a class does

Tailwind is not magic: every class is a normal CSS rule. Learn to look at it. In Preview press the button "open in a new browser tab" (the arrow next to the tab name), then open the developer tools (F12) and click the Elements tab.

  1. Select the heading. On the right you see the Styles: .text-2xl { font-size: ...; line-height: ... }. That is what the class makes.
  2. Untick a rule in the Styles panel to see the effect, or double-click a class name in the HTML to try another one. This is a fast way to experiment. (Copy what you like into your code afterwards.)

If a class seems to do nothing:

  • Is the class spelled exactly? text-2xl works, text-2-xl does not.
  • Is it inside a quoted string, with spaces between the classes?
  • Did the build fail? Look at the Vite messages with docker compose logs --tail 20 ws-main on your computer.
  • Tailwind only finds whole class names written in your files. A name built from pieces, like 'text-' + size, is never found.

Tailwind ไม่ใช่เวทมนตร์: ทุก class คือกฎ CSS ธรรมดา ฝึกดูมัน ใน Preview กดปุ่ม "เปิดในแท็บเบราว์เซอร์ใหม่" (ลูกศรข้างชื่อ tab) แล้วเปิด developer tools (F12) และคลิก tab Elements

  1. เลือกหัวข้อ ด้านขวาจะเห็น Styles: .text-2xl { font-size: ...; line-height: ... } นั่นคือสิ่งที่ class ทำ
  2. ติ๊กเอากฎออกใน panel Styles เพื่อดูผล หรือดับเบิลคลิกชื่อ class ใน HTML เพื่อลอง class อื่น เป็นวิธีทดลองที่เร็ว (แล้วคัดลอกที่ชอบลงโค้ดของคุณทีหลัง)

ถ้า class ดูเหมือนไม่ทำอะไร:

  • สะกดถูกตรงตัวไหม? text-2xl ใช้ได้ text-2-xl ใช้ไม่ได้
  • อยู่ในสตริงที่มีเครื่องหมายคำพูดและเว้นวรรคระหว่าง class หรือเปล่า?
  • build ล้มหรือเปล่า? ดูข้อความ Vite ด้วย docker compose logs --tail 20 ws-main บนเครื่องของคุณ
  • Tailwind หาเจอเฉพาะชื่อ class ที่เขียนครบ ในไฟล์ ชื่อที่ประกอบจากหลายส่วน เช่น 'text-' + size จะไม่ถูกพบเลย

Hint

The last point is the most common mistake in real projects: always write the full class name.
