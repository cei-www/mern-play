Step 1.2: Add the Tailwind plugin to Vite

Tailwind version 4 works as a Vite plugin: while Vite builds your page, the plugin reads your classes and produces the CSS. The package @tailwindcss/vite is installed already. You tell Vite to use it, in two places of one file: an import at the top and the plugin in the plugins list.

Tailwind เวอร์ชัน 4 ทำงานเป็น Vite plugin: ตอน Vite สร้างหน้าเว็บ plugin จะอ่าน class ของคุณและสร้าง CSS ให้ แพ็กเกจ @tailwindcss/vite ติดตั้งไว้แล้ว คุณบอกให้ Vite ใช้มัน ในสองตำแหน่งของไฟล์เดียว: import ที่ต้นไฟล์ และ plugin ในรายการ plugins

Edit client/vite.config.js (in the Explorer: style › client › vite.config.js). Write the code between the comments @tutorial:begin s1-2-vite-import and @tutorial:end s1-2-vite-import (near the top).

import tailwindcss from '@tailwindcss/vite';

Edit client/vite.config.js (in the Explorer: style › client › vite.config.js). Write the code between the comments @tutorial:begin s1-2-vite-plugin and @tutorial:end s1-2-vite-plugin (inside the plugins list, after react()).

tailwindcss(),

Save the file. Vite restarts by itself. Nothing changes on the page yet: the plugin is waiting for a CSS file that asks for Tailwind (next step).

บันทึกไฟล์ Vite จะรีสตาร์ตเอง หน้าเว็บยังไม่เปลี่ยน เพราะ plugin รอไฟล์ CSS ที่เรียกใช้ Tailwind (step ถัดไป)

Hint

The import is one line: import tailwindcss from '@tailwindcss/vite';. In the list, tailwindcss() is called like react(), with a comma after it.

Solution

In client/vite.config.js, between the comments of s1-2-vite-import:

import tailwindcss from '@tailwindcss/vite';
