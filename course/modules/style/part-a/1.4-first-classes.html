Step 1.4: Your first classes

Time for the quick win. The title Task Manager is an <h1>. Its class list is built in App.jsx. Add two classes: text-2xl (a larger text size) and font-bold (bold weight).

ถึงเวลาเห็นผลเร็ว ๆ ชื่อ Task Manager คือ <h1> รายการ class ของมันสร้างอยู่ใน App.jsx เพิ่มสอง class: text-2xl (ขนาดตัวอักษรใหญ่ขึ้น) และ font-bold (ตัวหนา)

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s1-4-title and @tutorial:end s1-4-title, in the class list of the h1.

'text-2xl font-bold',

Save. The heading changes at once, without reloading the page (Vite calls this hot module replacement). Try other sizes for fun: text-4xl, text-sm. Put text-2xl back afterwards, because the check looks for it.

บันทึก หัวข้อเปลี่ยนทันที โดยไม่ต้อง reload หน้า (Vite เรียกว่า hot module replacement) ลองขนาดอื่นเล่น ๆ ได้ เช่น text-4xl, text-sm แล้วใส่ text-2xl กลับ เพราะการตรวจมองหามัน

Open the app in Preview
