Step 1.1: What Tailwind is

You will make the Task Manager look good with Tailwind CSS. The page is the same React app you know. It starts unstyled: plain browser defaults. The API behind it is the finished one (you do not change it).

In regular CSS you invent a class name (.task-card), write its rules in a CSS file, and put the name in the HTML. Tailwind turns this around. It gives you thousands of tiny ready-made classes, each doing one thing, and you put them straight on the element:

คุณจะทำให้ Task Manager สวยด้วย Tailwind CSS หน้าเว็บคือแอป React ตัวเดิมที่คุณรู้จัก แต่เริ่มต้น ไม่มีสไตล์ เป็นค่าเริ่มต้นของเบราว์เซอร์ ส่วน API ด้านหลังเป็นฉบับสำเร็จ (คุณไม่ต้องแก้)

ใน CSS ปกติ คุณตั้งชื่อ class เอง (.task-card) เขียนกฎในไฟล์ CSS แล้วใส่ชื่อใน HTML Tailwind กลับด้านนี้ มี class เล็ก ๆ สำเร็จรูปเป็นพันตัว แต่ละตัวทำ อย่างเดียว แล้วคุณใส่บนองค์ประกอบได้เลย:

<li class="rounded-lg border p-3 shadow-sm">...</li>

rounded-lg rounds the corners, border draws a border, p-3 adds padding, shadow-sm adds a small shadow. You read the style from the element itself, and you never name or hunt for a CSS rule.

Tailwind reads your source files, finds the class names you used and writes only those rules into the CSS file. It is already installed in this project. You will connect it (Part A), then build the look step by step.

How the project works. The code is in client (React and Vite). Every element has its class list built with a small helper cx(...), for example className={cx('p-3', 'mb-2')}. Inside each list you will see comments @tutorial:begin ... and @tutorial:end ...: your classes for a step go between them. In real projects you write the classes in one string; the zones just let every step show you exactly where to type. Keep the comment lines.

rounded-lg ทำมุมมน border วาดเส้นขอบ p-3 เพิ่ม padding shadow-sm เพิ่มเงาเล็ก ๆ คุณอ่านสไตล์ได้จากองค์ประกอบเอง และไม่ต้องตั้งชื่อหรือไล่หากฎ CSS

Tailwind อ่านไฟล์ซอร์สของคุณ หาชื่อ class ที่ใช้ และเขียน เฉพาะกฎเหล่านั้น ลงไฟล์ CSS โปรเจกต์นี้ติดตั้งมาแล้ว คุณจะเชื่อมมัน (Part A) แล้วสร้างหน้าตาทีละ step

โปรเจกต์ทำงานอย่างไร โค้ดอยู่ใน client (React และ Vite) ทุกองค์ประกอบสร้างรายการ class ด้วยตัวช่วย cx(...) เช่น className={cx('p-3', 'mb-2')} ในแต่ละรายการจะเห็นคอมเมนต์ @tutorial:begin ... และ @tutorial:end ...: class ของแต่ละ step ใส่ระหว่างคอมเมนต์สองบรรทัดนี้ ในงานจริงคุณเขียน class ในสตริงเดียว zone เป็นเพียงให้ทุก step ชี้ได้ว่าให้พิมพ์ตรงไหน อย่าลบบรรทัดคอมเมนต์

Open the app in Preview and look at it now: no style at all. By the end it will look like a real product.

เปิดแอปใน Preview ดูตอนนี้: ไม่มีสไตล์เลย เมื่อจบจะดูเหมือนผลิตภัณฑ์จริง

Open the app in Preview

To start any step from a clean state, type for example tutorial goto 2.1 in the terminal of the Editor tab (it starts in the project folder). It writes the code of the earlier steps and empties the zones from that step on.

ถ้าอยากเริ่ม step ใดจากสถานะที่สะอาด ให้พิมพ์ เช่น tutorial goto 2.1 ใน terminal ของ tab Editor คำสั่งนี้เขียนโค้ดของ step ก่อนหน้า และล้าง zone ตั้งแต่ step นั้นเป็นต้นไป
