Step 5.2: Narrow screens

On a phone the two columns (groups and tasks) are too tight. Below md you want one column, with the group buttons in a row above the tasks, and from md up the groups as a column again.

  • max-md:grid-cols-1: the max- prefix applies below the breakpoint, so under 768px the grid has one column (it overrides the two columns of step 2.3).
  • md:flex-col: from 768px up the group buttons stack vertically; below it they stay in the row you made with flex flex-wrap.

บนโทรศัพท์ สองคอลัมน์ (group และ task) แคบเกินไป ต่ำกว่า md ต้องการ คอลัมน์เดียว โดยให้ปุ่ม group เรียงเป็นแถวเหนือ task และตั้งแต่ md ขึ้นไป group กลับเป็นคอลัมน์

  • max-md:grid-cols-1: prefix max- ใช้ ต่ำกว่า breakpoint ต่ำกว่า 768px grid จึงมีคอลัมน์เดียว (ทับสองคอลัมน์ของ step 2.3)
  • md:flex-col: ตั้งแต่ 768px ขึ้นไป ปุ่ม group ซ้อนแนวตั้ง ต่ำกว่านั้นอยู่ในแถวที่คุณทำด้วย flex flex-wrap

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s5-2-layout-narrow and @tutorial:end s5-2-layout-narrow, in the class list of the layout div.

'max-md:grid-cols-1',

'md:flex-col',
