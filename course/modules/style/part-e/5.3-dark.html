Step 5.3: Dark mode

The dark: variant applies when the user's system prefers a dark theme. Put a dark background on the page, light text on the title and a dark card for the rows.

This tutorial page is light only, but your app can have a dark mode. To see it without changing your computer: in the browser developer tools (F12), open the menu (three dots), More tools, Rendering, and set Emulate CSS media feature prefers-color-scheme to dark. (In Chrome. Other browsers have a similar option.)

variant dark: ใช้เมื่อระบบของผู้ใช้ตั้งค่าธีมมืด ใส่พื้นหลังมืดให้หน้า ตัวอักษรสว่างให้ชื่อ และการ์ดสีเข้มให้แถว

หน้า tutorial นี้เป็นโหมดสว่างอย่างเดียว แต่ แอปของคุณ มีโหมดมืดได้ เพื่อดูโดยไม่ต้องเปลี่ยนเครื่อง: ใน developer tools ของเบราว์เซอร์ (F12) เปิดเมนู (จุดสามจุด) More tools Rendering แล้วตั้ง Emulate CSS media feature prefers-color-scheme เป็น dark (ใน Chrome เบราว์เซอร์อื่นมีตัวเลือกคล้ายกัน)

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s5-3-dark-page and @tutorial:end s5-3-dark-page, in the class list of the outer div.

'dark:bg-slate-900',

Edit client/src/App.jsx (in the Explorer: style › client › src › App.jsx). Write the code between the comments @tutorial:begin s5-3-dark-title and @tutorial:end s5-3-dark-title, in the class list of the h1.

'dark:text-slate-100',

Edit client/src/components/TaskItem.jsx (in the Explorer: style › client › src › components › TaskItem.jsx). Write the code between the comments @tutorial:begin s5-3-dark-row and @tutorial:end s5-3-dark-row, in the class list of the li.

'dark:border-slate-700 dark:bg-slate-800 dark:text-slate-100',

Open the app in Preview

Hint

Each dark: class replaces the light value only in dark mode: bg-slate-50 stays for light, dark:bg-slate-900 wins in dark.

Solution

In client/src/App.jsx, between the comments of s5-3-dark-page:

'dark:bg-slate-900',

In client/src/App.jsx, between the comments of s5-3-dark-title:

'dark:text-slate-100',

In client/src/components/TaskItem.jsx, between the comments of s5-3-dark-row:

'dark:border-slate-700 dark:bg-slate-800 dark:text-slate-100',
