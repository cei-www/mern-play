Step 5.1: Mobile first: breakpoints

People use phones too. Tailwind is mobile first: a class without a prefix applies on every screen, starting with the smallest. A prefix such as sm: (640px), md: (768px) or lg: (1024px) adds a class that applies from that width and up.

So you write the phone version first, and only add what changes on larger screens. You already did this: the page padding is p-3 and the title text-2xl for phones. Now add sm:p-6 and sm:text-3xl: more room and a bigger title from 640px.

คนใช้โทรศัพท์ด้วย Tailwind เป็น mobile first: class ที่ไม่มี prefix ใช้กับ ทุก หน้าจอ เริ่มจากเล็กที่สุด prefix เช่น sm: (640px), md: (768px) หรือ lg: (1024px) เพิ่ม class ที่ใช้ตั้งแต่ความกว้างนั้น ขึ้นไป

คุณจึงเขียนเวอร์ชันโทรศัพท์ก่อน แล้วเพิ่มเฉพาะสิ่งที่เปลี่ยนบนจอใหญ่ คุณทำแบบนี้มาแล้ว: padding ของหน้าคือ p-3 และชื่อหน้า text-2xl สำหรับโทรศัพท์ ตอนนี้เพิ่ม sm:p-6 และ sm:text-3xl: พื้นที่มากขึ้นและชื่อใหญ่ขึ้นตั้งแต่ 640px
