Step 6.2: Final check

The final check looks at your project as a whole:

  • the project builds without errors (vite build);
  • your classes use hover, a breakpoint (sm:, md: or lg:) and dark mode;
  • there is no inline style= anywhere: styling is done with classes.

The check cannot judge how the page looks. Do that yourself: open Preview in a full browser tab, resize it, try the light and the dark mode, tab through the page with the keyboard, hover and press the buttons. Compare with your own idea of a good Task Manager.

การตรวจสุดท้ายดูโปรเจกต์ของคุณทั้งหมด:

  • โปรเจกต์ build ได้โดยไม่มี error (vite build)
  • class ของคุณใช้ hover breakpoint (sm:, md: หรือ lg:) และ dark mode
  • ไม่มี style= แบบ inline เลย: การจัดสไตล์ทำด้วย class

การตรวจตัดสินไม่ได้ว่าหน้า ดูเป็นอย่างไร ให้คุณทำเอง: เปิด Preview ในแท็บเบราว์เซอร์เต็ม ปรับขนาด ลองโหมดสว่างและโหมดมืด กด Tab ไปทั่วหน้าด้วยคีย์บอร์ด เลื่อนเมาส์และกดปุ่ม แล้วเทียบกับภาพในใจของคุณว่า Task Manager ที่ดีควรเป็นอย่างไร
