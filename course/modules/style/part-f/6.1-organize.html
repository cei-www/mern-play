Step 6.1: Keep long class lists tidy

Look at the class list of a task row now. It is long. That is normal in Tailwind, and it is fine if you handle it well:

  • Extract components, not classes. When you copy the same long list in many places (every button of the app), make it one React component (<Button>) and keep the classes there once. This is Tailwind's main answer to repetition.
  • Sort the classes. A fixed order (layout first, then spacing, type, colors, states) makes a list easy to scan. The official prettier-plugin-tailwindcss sorts them for you when you save. (It is not installed in this workspace; in your own projects add it with npm install -D prettier-plugin-tailwindcss.)
  • Use the theme. A color or a size you use in many places belongs in @theme (step 3.4), not repeated as an arbitrary value.
  • Read, do not fight. If a class is not working, look in the developer tools (step 1.5) which rule wins, instead of adding more classes.

In this course the classes of each step were kept in separate zones so that every step shows exactly where to type. In a real project you would write one string per element, in the order above.

ลองดูรายการ class ของแถว task ตอนนี้ มันยาว ซึ่งเป็นเรื่องปกติของ Tailwind และไม่เป็นไร ถ้า จัดการให้ดี:

  • แยกเป็น component ไม่ใช่แยก class เมื่อคุณคัดลอกรายการยาว ๆ เดียวกันหลายที่ (ปุ่มทุกปุ่มของแอป) ให้ทำเป็น React component เดียว (<Button>) และเก็บ class ไว้ที่นั่นครั้งเดียว นี่คือคำตอบหลักของ Tailwind ต่อการซ้ำ
  • เรียง class ลำดับตายตัว (layout ก่อน แล้ว spacing, type, สี, state) ทำให้สแกนรายการได้ง่าย prettier-plugin-tailwindcss ทางการจะเรียงให้เมื่อคุณบันทึก (workspace นี้ไม่ได้ติดตั้งไว้ ในโปรเจกต์ของคุณเองให้เพิ่มด้วย npm install -D prettier-plugin-tailwindcss)
  • ใช้ theme สีหรือขนาดที่ใช้หลายที่ควรอยู่ใน @theme (step 3.4) ไม่ใช่เขียนซ้ำเป็น arbitrary value
  • อ่าน ไม่ใช่ต่อสู้ ถ้า class ไม่ทำงาน ให้ดูใน developer tools (step 1.5) ว่ากฎไหนชนะ แทนที่จะเพิ่ม class

ในคอร์สนี้ class ของแต่ละ step ถูกเก็บใน zone แยก เพื่อให้ทุก step ชี้ได้ว่าให้พิมพ์ตรงไหน ในโปรเจกต์จริงคุณจะเขียนหนึ่งสตริงต่อหนึ่งองค์ประกอบ ตามลำดับข้างต้น
