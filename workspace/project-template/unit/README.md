# Unit testing the Task Manager

The code you test is in `src/`. You only write tests, in `tests/` (files named `*.test.js` or `*.test.jsx`).

```
npm test            run all tests once
npm run test:watch  run tests again whenever you save
npm run coverage    run all tests and show which lines they touch
```

Follow the lessons on the left. They tell you which file to create and what to put in it.
